The first release of Apunta for Linux.

- First-run setup: on a computer without them, Apunta offers to download its speech and writing models, shows what each one is and how big it is, and downloads nothing until you press Download.
- Quitting is quick again: the app no longer waits about 16 seconds to close.
- Error messages about a missing model now point to the setup notice instead of Settings.
- From this version on, Apunta can update itself. You can turn update checks off in Settings.

Everything still runs on this computer. Updates are checked against this page only, and every download is checked against Apunta's signing key before it is installed.
