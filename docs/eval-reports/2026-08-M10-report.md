# M10 — first contact with a real model

The first time any part of this project ran against real model weights.
Everything before this packet — 897 unit tests, 35 e2e, ten build packets —
ran against fake providers.

## The machine, honestly

The owner's partner's Linux PC: AMD Ryzen 7 9800X3D (8 cores), 30 GiB RAM,
Arch Linux, Node v26.7.0. A Radeon RX 9070 XT is present but idle — this
Ollama build detects no ROCm/Vulkan device, so every number here is
**CPU-only inference**. Ollama **0.32.15**, which is exactly the release
`scripts/package-mac.sh` pins into the Mac bundle: the runtime certified
here is the runtime she ships.

What transfers to the 8 GB M2 target and what does not: model behaviour —
what it fabricates, what it leaves blank — is a property of the weights and
the deterministic sampling (temperature 0) and transfers. Speed does not:
Metal offload on 8 GB shared memory is its own experiment, as is macOS
memory pressure with a browser open. Treat every tokens/sec below as "a
mid-range desktop CPU", nothing more.

## Step 1 — the three tags exist

All three verified against the live registry (manifest HTTP 200);
`shared/src/models.ts` needed no change. The shipping tier was pulled:
`qwen3.5:4b-q4_K_M`, 3,389,983,735 bytes, 4.7 B parameters, 262 144

## Step 2 — smoke: 5/5 clean

`npm run build && npm run smoke:live -- --model qwen3.5:4b-q4_K_M --runs 5`
on the 660-word fixture: every run schema-valid, no repetition loop
(ollama#15502 never fired here, nor across ~180 eval generations), prompt
within context. 299 output tokens, byte-identical across all five runs.
15.4–16.8 tok/s generation, prompt 2622 tokens, cold load 1.35 s.

## Steps 3–4 — the evals, and what it took to make the instructions hold

All runs: 20 fixtures × 3 runs, temperature 0. Determinism made every
failure exactly reproducible — 3/3 or 0/3, nothing in between — so each
fixture is effectively a single boolean experiment.

| Arm | Fabrication rate | Gated runs | Report |
| --- | --- | --- | --- |
| Baseline (default instructions) | **40.0%** | 24/60 | `2026-08-baseline-4b.md` |
| Owner instructions, as first distilled | 65.0% | 39/60 | in git history (commit 8235277) |
| … revision 1: scoped absolutes, restored self-check | 55.0% | 36/60 | in git history (commit 9f54382) |
| … revision 2: de-primed, narration class, verbatim terms | 50.0% | 33/60 | in git history (commit b997c34) |
| … revision 3: a worked example (**shipped**) | **40.0%** | 27/60 | `2026-08-tuned-4b.md` |

Read the delta per format: `--instructions` replaces the **progress**
instructions only, so the six intake fixtures ran identical instructions in
every arm and their failures never move (verified: their rows are
byte-identical across arms). Four intakes gate in every arm — 09
(declined-history regurgitation), 10, 16 (invented gender), 19 — and
whatever fixes them must go into the intake instructions or the pipeline,
not this file.

The instruction file's git history carries each revision and its measured
effect; the short version:

- The distilled file, as handed over, was **harmful**: it fixed none of the
  baseline's failures and broke six fixtures the baseline passed. Its
  absolutes ("nothing she said may disappear") lacked the counterweights
  the defaults have (per-section relevance, worked examples, a closing
  self-check), so the 4B followed them off a cliff — absorbing asides and
  retracted content, inventing observation language on a phone check-in,
  blanking a 19-word note entirely.
- Revision 1 scoped the absolutes and restored the missing self-check:
  −10 points.
- Revision 2 learned two small-model lessons the numbers taught:
  never quote a phrase you are forbidding (the 4B echoed "consistent with"
  back out of the prohibition itself), and name narration-about-the-session
  as its own excluded class. −5 more, but three fixtures kept shrugging
  off rules written straight at them.
- Revision 3 added the counterweight the defaults always had and the
  distilled file never did: **one worked example**, in her real seven
  sections, whose source contains an option raised and dropped, small
  talk, an everyday word, and no mention of risk. −10 points at a stroke.
  On this model a demonstration outranks any rule; that is the
  transferable lesson for the intake instructions too.

Where the shipped configuration stands against baseline, beyond the equal
headline: **zero** gating unsupported-conclusion hits (baseline had 3 —
fixture 17, which the baseline itself failed, now passes), novel
diagnosis/risk terms 9 vs 12 (fixture 15 also now passes), unsupported
conclusions per section 0.0% vs 1.4%, blanks preserved 100% vs 93%. The
costs, stated plainly: fixture 01 (a 19-word jotting) comes back with
every section blank — an S4 gate, the safe-direction failure she can see
at a glance and the reason gated runs read 27/60 against the same 24
fabricating runs; and fixtures 04 and 18 still carry things she said but
set aside (a declined scheduling option; an aside she flagged as not
clinically relevant). Those two are inclusions of real speech, not
inventions, and they survived four instruction versions: on this model
they look like a decoding-stage problem, not a prompting one. The
measured next lever is section-at-a-time drafting (M9's per-note
summarise stage shows the pattern) — a code change, justified now by two
deterministic failures that instructions demonstrably cannot reach, and
sized for a future packet rather than this one.

## One note read by hand, end to end

The shipped configuration was also exercised the way she will use it: the
config pack restored into a fresh data dir, fixture 02's dictation typed
into the capture screen, drafted by the real 4B into her seven sections.
The result, judged by hand: faithful on facts — correct first-name voice,
blank Risk review because risk never came up, no invented observations,
numbers all hers. Three real flaws: "Friday session" was routed into
Location (a day is not a place; the section should have been blank), "I
want to start him on grounding exercises" became "I introduced grounding
exercises" (intent inflated into a completed intervention — the F5 class
the automatic rubric cannot see), and the weekly session cadence was
folded into the thought-records sentence. Usable as a draft she edits;
not signable as-is; consistent with what the numbers above say about
this model.

## Speed on this machine

~15–16 tok/s generation, ~16 s mean per note (≈200-token notes), ~2 K-token
prompts. Both eval arms ≈ 16–17 minutes wall clock for 60 notes.

## What failed, and what to watch on the Mac

- CPU-only here. If her Mac's Metal path behaves differently under memory
  pressure, the smoke run (5 minutes) answers it cheaply — run it there.
- The four still-failing intakes are a property of the **default intake
  instructions** on this model, not of her file. An intake-side pass of the
  same distillation discipline is the obvious next packet-sized job.
- Fixture 15's gate ("invented a plan") may be a routing artifact — the
  rubric's own §11 warns its label can be wrong. Hand-read before treating
  it as a model failure. Same for the F7 hits on 06/19: read the notes.
- ollama#15502 (repetition under grammar-constrained decoding): never
  reproduced, 185+ generations. Either 0.32.15 fixed it or this model
  doesn't trigger it; keep the 5-run smoke as the Mac's first check anyway.
