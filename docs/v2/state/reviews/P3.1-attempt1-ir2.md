### Ownership residual — **CLOSED**, and by a mechanism that is real here.

**Is it real on this platform?** Yes. The listening socket for a `127.0.0.1`
port appears in `/proc/net/tcp` (I read the header, and the file is
world-readable) with its inode in column 10; the owning process holds that
inode as a `socket:[N]` symlink under `/proc/<pid>/fd` (I read
`/proc/self/fd` unprivileged). `ss -ltnp` does the join for you and returned
pid/fd pairs for six listeners with no elevation. The server binds IPv4
exclusively — `config.host` is the literal type `'127.0.0.1'`
(`config.ts:73,156`), `index.ts:134` and `boot-error.ts:82` both pass it to
`app.listen` — so `/proc/net/tcp` is the right file and there is no IPv6 gap.

**Is it inside May edit and unprivileged?** Yes. The assertion lives in
`scripts/v2/package-linux-resources.test.sh`, a **new** file already in May
edit (`cards/P3.1.md:39-40`), and it only reads `/proc` and runs `ss`
(`/usr/bin/ss`, reachable under the card's own `PATH=/usr/bin:/bin` at
`:250-251`). It writes nothing and grants nothing.

**Can it be satisfied while a foreign process serves the port?** I attacked
this specifically and could not build a case. The assertion is an *identity*
join, not a liveness check: if a foreign process holds the listening socket,
the inode in `/proc/net/tcp` belongs to *it*, and the match against
`/proc/<ourpid>/fd` fails. The two ways to think of defeating it both fail:

- *Bind a different local address on the same port* (e.g. `127.0.0.2:<p>` while
  the server holds `127.0.0.1:<p>`). The server's socket still receives every
  connection to `127.0.0.1:<p>`; the foreign socket is not the one answering,
  so the assertion is correct rather than fooled.
- *Two listeners on one `127.0.0.1:<p>`.* Requires `SO_REUSEPORT`, which
  `app.listen` does not set. Not reachable.

The only residual is an ordinary TOCTOU — a check at T, a kill-and-rebind
between T and the next assertion — which is the same shape as C-ISO@1 rule 2's
own bind-then-release, and is not a specification defect. **The residual named
in the previous pass is closed.**
