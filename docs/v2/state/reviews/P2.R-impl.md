## 3. Deviations and disclosures I verified rather than accepted

- **`TopBar.test.tsx:102` is a vacuous line, and the return says so.** I
  reproduced the mechanism with jsdom directly: given
  `<svg viewBox="0 0 2903 1012">`, `querySelectorAll('svg[viewBox="0 0 2903
  1012"]')` matches **0** while `getAttribute('viewBox')` returns the value. The
  assertion at `:102` therefore passes whether or not a wordmark is present. It
  is not a hole: `:98` uses `queryByRole('img', { name: 'Apunta' })`, which
  testing-library computes without a CSS selector, and `:103`'s
  `querySelectorAll('svg')).toHaveLength(1)` has teeth, because the back branch
  of `TopBar.tsx:30-37` renders `BackIcon` and nothing else. Same mechanism is
  why `HomeLauncher.test.tsx:37-39` matches the viewBox value by hand; that
  choice is correct and the e2e can use the selector verbatim because a real
  browser resolves it (V1 counted exactly one match).
- **`PUT /api/settings` is a merge and cannot unset a key.** Observed in both
  e2e runs: `beforeAll` read `{}` (both keys absent on a fresh per-run
  database) and the restore left `theme="light"`, `accent_color="#1f6f63"`
  stored. On a fresh sandbox database those *are* the resolved defaults, so no
  sibling spec can be affected, and the spec printed the discrepancy and its
  reason rather than hiding it. The row's "restored to the values `beforeAll`
  read" is satisfied in substance; the spec's `afterAll` asserts every key that
  *was* present is back, which is the strongest form available over a merge.
- **The four `--accent` invariance checks really ran.** They are guarded by
  `if (reference !== undefined)` over a module-level `Map` (`brand.spec.ts:193`),
  so they would go quiet if the order ever changed. They are taken today:
  `mode: 'serial'` with one worker in declaration order, and the two
  non-default states are the ones that read a reference. The absolute per-state
  pairs at `:191-192` pin the same values independently, so nothing is
  unpinned either way.
- **Both children's unresolved items are honest and correctly left unfixed.**
  `MarkIcon` still has zero importers (`grep -rn MarkIcon web/src e2e` returns
  the definition at `icons.tsx:25` plus two comment/test mentions); the A mark
  still renders only at `HomeLauncher.tsx:73`; the dead `.home-mark` rule is
  still at `app.css:2928-2931`; `DECISIONS.md:24` still reads wider than the
  code. Every one of those is a card stop condition — report, change nothing —
  and nothing was changed. Correctly escalated to the coordinator.

   `getComputedStyle` reads each element's own colour, not a composited
