- **Where:** `docs/v2/cards/P3.6.md:397`, V3's expected cell.
- **Conflicting text.** *"The generator substitutes `{{BASE}}` and nothing else,
  so an angle-bracket form reaches git as a pathspec that matches nothing …"*
  and, a few clauses earlier, *"the primary predicates are `git diff
  --name-only {{BASE}}...HEAD -- <Rule B set>`"*.
- **The mechanism, read in the generator at `ee0d562` and not assumed.** For an
  implementation card the body is `card.text` **verbatim** (`:123`); the only

  Measured on git 2.55: `git diff --name-only '{{BASE}}...HEAD' -- <set>` →
  **`fatal: bad revision`, exit 128**, and the U+2026 form likewise 128 while

  prints changed paths on a dirty one (round 4's D8, still closed).
- **Failure scenario.** P3.4 and P3.5 are approved, a dispatch is generated with
