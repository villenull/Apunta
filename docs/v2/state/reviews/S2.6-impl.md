   this card cannot fix it. Not caused by this attempt, and not cured by it.
   MAJOR (blocking the card's approval; the file is out of scope).**
   The case leaves the workspace with `page.getByTestId('home-link').click()`,
   which is `<Link to="/">` at `web/src/components/PatientsColumn.tsx:268`, while
   the page is already at `/` (`page.goto('/')` at `:399`). React Router adds no
   history entry, so the history is `[about:blank, /]` and `page.goBack()` lands

   by a different link. **What would make it pass:** leave for a route that
   pushes a real history entry before `goBack()` — for example navigate to
   Settings and back, or click the `Patients` link from a non-`/` screen — which
   is a recommendation only. This file is the UI owner's after the AM-063
   retarget and is not in this card's May-edit, and I have not touched it. I
