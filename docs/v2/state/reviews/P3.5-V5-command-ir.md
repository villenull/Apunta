## IR-04 — DEFECT — a missing or empty read is read as zero leak

`grep -cF … "$b/$l"` answers `0` for an **empty** file, and
`grep -qF … "$b/default-source"` finds nothing in an empty file, so both read as
clean. The four `||` guards only catch a **non-zero exit**; a `pactl` that
succeeds and prints nothing is unguarded.

```
FAKE_DEFAULT=empty FAKE_SOURCES=empty FAKE_SINKS=empty FAKE_MODULES=empty   -> ROW EXIT=0
FAKE_MODULES=empty (alone)                                                -> ROW EXIT=0
FAKE_SOURCES=empty (alone)                                                -> ROW EXIT=0
FAKE_SINKS=empty (alone)                                                  -> ROW EXIT=0
```

Expected says `pactl get-default-source` "prints the host's real default
again". A blank line is not that, and it exits 0. `pactl list short sinks` and
`modules` legitimately print nothing on a bare session, so this is not a
hypothetical input.

**Minimal fix, no new criterion:** require each capture to be non-empty before it
is examined — `test -s "$b/default-source"` and `test -s "$b/$l"` inside the same
`|| { …; bad=1; }` shape the command already uses. This asserts nothing the
Expected does not already assert; it makes "prints … again" mean what it says.
