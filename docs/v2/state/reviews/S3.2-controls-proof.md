## 3. Exact proposed clause corrections

One clause each, in text that already exists: G1–G3 are additions to rule (1)'s list at
`:573-576`, everything else a replacement.

**B-1 — the token sits in the negator's slot** (`:591-595`, `:622-627`, `:650-663`):
`"{{lexicon}} no refiere"` → `"{{lexicon}} refiere"`; `"{{lexicon}} no reporta"` →
`"{{lexicon}} reporta"`; `"{{lexicon}} jam[aá]s"` → **dropped**, and `"{{lexicon}} ha
tenido antecedentes de"` added to keep the coverage behind a phrase; `"{{lexicon}}
niega(?:ndo)?"` → `niega(?:ndo)?`; `"{{lexicon}} no puede dormir"` → the gold's own
single-clause alternatives with the token in each negator slot. An entry whose negator
is a verb (`niega`, `nega`) or `sin` — none in the nine-term inventory — carries no token
and stays an authored literal.

**G1** (new): *an entry consisting of nothing but `{{lexicon}}` is a `CorpusError`.*
**G2** (new): *the literal word following `{{lexicon}}` may not itself be a negator of
the inventory or of `sin`/`niega`/`nega`/`sino`.* **G3** (new): *a control in the
invented-negation class must contain no inventory negator in its `controlSource`.*
All three are load-time refusals naming the control's key; each is demonstrated failing.

**G1/G2 are surface-syntax checks, and this report claims no more.** As proposed clause text
they forbid exactly the two literal shapes round 1's defects take — an entry that is nothing but
the token, and a token followed by a literal second negator. They read the entry **as written**,
so an equivalent-in-effect regex form is not detected. Measured in the new case `G1/G2 are
surface-syntax checks…`: `(?:{{lexicon}})` is not "nothing but the token" as a string, so it
**loads** (exit 0) and still fires on the negator alone, flagging a faithful restatement;
`{{lexicon}}\s*no\s+refiere` puts no literal negator directly after the token (the first letter
group is `s`, out of `\s*`), so it **loads and then misses** the invented negation (exit 3) while
demanding a doubled `No no refiere`. Closing that class generally needs a parser for the sidecar's
regex language — a production design decision, **not adopted and not built here**.

**G3's class, and the schema delta it would need.** The class is derived from the
control's own `mechanism` (`F1 banned string` → invented-negation), so there is no
self-declared opt-in to forget; round 2's `precondition: "negation-free-source"` existed
only in this proof. There is therefore **no marker to omit, and omitting one cannot bypass
the clause**. The one residual lever is the value of `mechanism` itself: relabelling a
control whose source legitimately carries an inventory negator to something other than
`F1 banned string` loads at exit 0, and a bare inventory entry such as `jam[aá]s` then
fires on the source's own negation. That is an **extension limit**, not an omission bypass
and not a contradiction of any claim above: the class is *defined* as that mechanism value,
so a relabelled control is outside the class and therefore outside the clause by
construction. Within this proof's four controls the derivation is exact. The limit bites only
if the real sidecar carries a different field — the scope the closing paragraph below and L1
already name. The proof *does* propose one optional sidecar key — a **proposal, not
an adoption**: `negationClass`, absent meaning "derive it", and a value outside
`invented-negation | other` or contradicting `mechanism` is a load-time `CorpusError`, not
a silent downgrade. No shipped schema here carries `negationClass` or `mechanism`; if the
real sidecar schema has neither, adopting G3 as written needs a schema addition an owner
would have to accept, and the derivation would have to be re-derived from whatever field
the real sidecar does carry. Stated, not designed around.

**B-2 — locale scoping** (FD6 key table `:996`): only the two es-MX controls carry
`"lexicon": "negation"`; the two `en` controls carry no key and no token and score the unchanged
legacy path (`:578-585`). Add: no English negation lexicon exists and this card authors none.
**B-3 — blinding ordering** (rule (4)): the zero-term check runs on the lexicon **as authored on
disk, before any blinding**, so "empties that lexicon" in FD1 `:483-485` and FD8 `:1167-174`
becomes "substitutes `(?!)` for that lexicon's vocabulary". **M-1**: `(?:)` is wrong because the
*corrected* `(?:) refiere` matches any note mentioning the verb; `(?!)` stands. **m-2**: the
vocabulary is matched against NFC text, `es-MX.txt` is authored in NFC, the boundary does not
match NFD, and the clause must name the **inventory**, since no other term is affected.
**m-3/m-4**: `11`, not `12`, characters; FD5's refusal is pre-flight, and its evidence is an
exclusive create under a path this run owns.

### 3a. Exact synthetic slot coverage, and where it differs from gold

**No parity claim.** The correction is authored for this proof's synthetic source (`ES_INV_SOURCE`), not the gold's. Measured against `eval-es/tuning` `invented-negation/01-todos-los-dias.txt`: **caught** — `no refiere`,
`no reporta`, `no reporta ejercicio` (via `{{lexicon}} refiere` / `{{lexicon}} reporta`)
and `sin antecedentes de`, `nega tener`, `niega(?:ndo)?` (token-free literals), i.e.
**5 of the 8 literal gold entries**; **not caught** — `se descarta`, `sin ejercicio`,
`obsesidad`, plus `no (?:hace|realiza) ejercicio`, `sin actividad f[ií]sica`,
`sedentari[oa]s?`, `inactiv[oa]s?`, `descartad[oa]s?` and the cardiometabolic
`trastorno de …` / `diabetes …` / `crisis de …` entries (out of scope for a
hypertension/walking source); **partial** — `no (?:camina|caminar|realiza actividad)`
(catches `No camina …`, not `No realiza actividad …`) and `no (?:refiere|menciona)
ejercicio` (the `menciona` branch only); **dropped on purpose** — `jam[aá]s`, the bare
entry G3 exists for. **The mechanism claim stands; the slot list does not generalise to
the gold.**

`controlSections`); B-2 (exit 2 at load under `--locale en`; English loads the legacy path

**Still open, deliberately not guessed.** G1/G2 do **not** close the loophole universally
(L4, §3) — surface-syntax checks, equivalent regex forms measured, and closing that generally
is a production design decision this proof does not make. Synthetic slot coverage is **not**
gold parity (§3a). "Every inventory term reaches every slot" is about the substitution
mechanism; which term reads grammatically in which slot (`nada camina`, `nadie menciona`) is
the sidecar author's call and is **not measured here**. **L1**: `assertFixture` is not called,
so a sidecar that loads here may still be refused in production — and the same limit now
covers G3's classification, which reads `mechanism`, a field this proof's own sidecars carry
because this proof wrote them (the residual lever, relabelling that field, is named in §3
and classified there as an extension limit, not a bypass). **L2**: no production acceptance,
no card acceptance. The
**`en` detection mechanism** stays minimal and authored (`denies`, `denying`,
`never (?:takes?|took)`; `sleeping well again` and three siblings); the real pair must come
from the same sources as the class's real detection. **F7 source validity under
`--locale es-MX`** stays an `en` test by the proposal's own reasoning; neither V2 nor this
proof exercises it.
