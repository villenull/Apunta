## The central question: does the widened May edit make V2 reachable?

**Answer: no. It widens the grant correctly and still leaves the row unreachable,
for a reason that is measurable without running anything.**

Three facts, all read in committed source:

1. **The controls half of V2 never sees the fake.** FD6 `:852-860` says a control
   "is scored on its injected text, never on model output … `scoreNote` is the
   same function in both cases; only the provenance of the text differs."
   Controls are scored on `controlNote`; `fakeSectionsFor` is never on their path.
   Attempt 1 measured the consequence directly: **all ten es-MX controls behaved
   exactly as FD6's predicates state, each named mechanism printed.** So the
   controls half of V2 already holds and the widened `fake.ts` cannot change it.
2. **V2's exit code comes from somewhere else entirely.** In `--fake` mode,
   `cli.ts:416-432` exits 0 only when `sensitivity(lastModels).deflects` is true,
   and `run.ts:267-284` defines that as
   `bannedStrings > 0 && gatingConclusions > 0 && filledBlanks > 0 && cleanFixtures > 0`
   over the **33 corpus fixtures'** scores (`models.flatMap(m => m.scores)`), not
   over the controls. Attempt 1 exited 1 because this was false.
3. **Two of the four conjuncts are what "populate the sections" can fix; the third
   it cannot, at all.** I measured each conjunct's reachability statically over
   `e2e/fixtures/eval-es/tuning/**` (33 fixtures, 11 trap-type directories, 3 with
   `f6: "gating"`, 3 declaring a `blank` section):

   | Conjunct | Reachable by filling sections with source text? | Evidence |
   | --- | --- | --- |
   | `bannedStrings` | **yes, in principle** | F1 currently hits **0 of 33**: no fixture's `mustNotContain` matches its own `condense(source)` section-0 body. 4 of 33 fixtures' **full** transcripts do match, and those matches sit past the 240-char condensation. Filling later sections with source text can produce F1 hits. |
   | `filledBlanks` | **yes** | only 3 fixtures declare a `blank` section, none of them section 0; `score.ts:456-461` gives `blankOutcome === 'filled'` only for a non-empty blank-expected section, and every one of those is index ≥ 1, i.e. `''` today. |
   | `cleanFixtures` | already true | any fixture with empty `gating`. |
   | **`gatingConclusions`** | **no — structurally zero** | `gatingF6` (`score.ts:319`) requires `fixture.f6 === 'gating'` (3 fixtures) **and** `f6CoreHits.length > 0`, and `score.ts:477-486` computes `f6CoreHits` **only** from sections listed in `noConclusion` and **only** for a marker absent from the source. `f6Core()` (`patterns.ts:15`) is **English-only** (`consistent with`, `indicates`, `respond(s|ing) to`, `differential`, …). I grepped all 66 Spanish tuning transcripts in both Spanish corpora for that alternation: **0 files contain any marker**. A Spanish note assembled from Spanish source text therefore cannot produce one `F6 unsupported conclusion`, no matter how many sections the fake fills. |

The only way to satisfy `gatingConclusions > 0` on this corpus is for the widened
fake to **inject English f6Core vocabulary into a Spanish-named section** of one of
the three gating fixtures. The May edit does not name that, does not require it, and
does not say whether it is permitted; the natural reading of "letting the fake
populate the sections the controls need" points the implementer somewhere else
entirely.

**Concrete failure scenario for attempt 2 as the card now reads it.** The
implementer widens `fakeSectionsFor` to give every unmatched section a condensed
body. `filledBlanks` and `bannedStrings` go non-zero, `cleanFixtures` stays

failed and no instruction about whether to widen the fake further, narrow the fake,
report a FAIL, or stop. The same row burns the same attempt for the same reason.

**Could the widened fake make V2 pass for the wrong reason? Yes, and this is the
second thing to look for.** Note carefully that the two halves of V2 are not the
same instrument. The *controls* half is the scorer deflecting on injected text —
refusing to invent, marking what it cannot know — and it is unaffected by the fake
