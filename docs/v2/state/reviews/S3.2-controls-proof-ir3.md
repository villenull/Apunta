## Non-blocking comments (recorded, not blocking; none needs a code change)

1. **G3's clause sentence reads permissive.** §3 line 71: "*a control in the invented-negation class
   **may have** a `controlSource` containing no inventory negator*" — but the implementation
   **enforces** (`CorpusError`). The next sentence ("All three are load-time refusals") resolves it,
   so no reader is misled overall; still, an owner adopting the clause text verbatim from that one
   line would read it as optional. **One-word prose fix: "must contain no".**
2. **G3's residual lever is `mechanism`, and it is disclosed but not named.** `R2`: relabelling
   `mechanism` to `missed mustCapture` on a control whose source carries `jamás` loads at exit 0,
   and the bare `jam[aá]s` entry then fires on the source's own negation — the exact hazard G3
   exists for. This is **not** an omission bypass (there is no field to omit) and **not** a
   contradiction of any claim: §3 defines the class *as* `mechanism === 'F1 banned string'`, so a
   control outside that definition is outside the clause by construction. It is an **extension
   limit**: if the real sidecar schema carries a different field, the derivation must be re-derived
   from it — which §3's closing paragraph and L1 both say. Suggested addition: one clause naming
   `mechanism` as the only lever, beside the existing "no opt-in to forget".
3. **"Cannot omit the marker to bypass" is now literally true and worth saying.** It was not in
   round 2; `R2` measures it. Recording it costs a clause and forecloses the next reviewer
   re-asking.
4. **G1/G2 hold only on the literal shapes.** True and disclosed (L4). No action.
5. **The correction's `mustNotContain` for `CORRECTED.lost` is entirely token-free**, so the lost
   control exercises only the restatement half of B-1; the token half is exercised by
   `CORRECTED.invented`. Correct as written and measured; noting the split so the next reader does
   not read the lost control's seven `mustCapture` alternatives as lexicon-substituted. (They are
   checked slot-wise by the target's own case, and `R3` confirms the token-free `sigue sin dormir
   bien` alternative still captures.)

  the target says so rather than implying otherwise. I did not fuzz the regex language.
- **G3 does not unjustifiably classify unrelated controls *within the bounded set*.** The task
  asked me to separate extension limit from claimed contradiction: with the proof's four controls,
  the two `F1 banned string` ones are exactly the invented-negation pair and the two

  repeated in the header, §1, §4 and L2.
