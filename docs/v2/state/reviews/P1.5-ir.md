**IR-03 (behaviour, data shape, rules) — closed, all five gaps.**
1. *Mechanism*: named per tag, with the two page URLs, and the alternative
   `ollama show <tag> --license` gated on `ollama list` already showing the tag
   (permitted as an already-installed tool by `ACQUISITION.md` §2). The card
   defines what a read is — the licence text itself, from the blob or the page —
   and excludes a licence "named from memory, from the registry listing, or from
   another tag's evidence". It restates that the card never pulls, removes or
   replaces a tag, with A08's S5.6 assignment.
2. *Destination*: `licence.url` keeps naming the library page (which is what
   the field documents at `catalog.ts:67`), the read date goes in the entry's
   existing code comment (precedent cited at `catalog.ts:195-197`) and in
   `docs/v2/evidence/P1.5/licence-evidence.md` with tag, URL, date and the text
   as read; a local-blob identifier goes in the evidence file, never in `url`;
   adding a field to `LicenceReference` or `SetupEvent` is forbidden — correct,
   since `LicenceReference` has three fields and `SetupEvent` is derived from
   `SetupEventSchema` (`protocol.ts:24`, `:106`).
3. *Support for the value*: `verified: true` is admissible only with a read and
   that read's URL and date; the publisher-neutral `'Gemma Terms of Use'`
   (`catalog.ts:186`) stays until then; `(plan reference E9)` is correctly
   identified as the L-POLICY *policy* row at `docs/v2/DECISIONS.md:47`, which
   says nothing about gemma4, so `Apache-2.0` is written only if the read
   returns the Apache License 2.0 text — in the same edit as `verified: true`.
4. *HANDOFF*: the bold line at `docs/HANDOFF.md:466` is kept (explicitly not
   converted to a `###`, not deleted) and filled with a bullet list, one bullet
   per removed item, under a selection filter that names the rows: the owner
   scope cleanup (`:225` — vocabulary acquisition, A/B experiments, the Tailscale
   invite), the Mac pause (`:227`) and the model-switch declinations
   (`:231`-`:234`) — verified against the file, and against the same day's
   additions (`:228` Halaxy as M13, `:240` Inter, `:241` Keep mine / Take
   theirs) which the filter excludes. The empty-filter branch (delete the line,
   say so in evidence) is now decided by the filter rather than by a second
   guess.
5. *qwen3.6*: covered by the same rule as gemma4 — it keeps
   `name: 'Apache-2.0', verified: false` (`catalog.ts:180`) and stays `false`
   unless its own licence text is read, and the first stop condition names both
   tags.

**IR-08 (the read was not permitted, and had no stop response) — closed.** The
new "Egress (this card only)" section does the work round 1 asked for, in the
card's own words: HS-3 permits only what `ACQUISITION.md` lists and lists no row
