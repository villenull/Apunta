## Verdict in one line

The dictionary is bundled, licence-handled exactly as AM-203 requires, loaded only
from the app's own origin, and the English path is provably unchanged — but the
locale-switch path this card exists to get right loses the dictionary silently
after a mid-session language change, and neither the code nor the two V1(f)
cases that are meant to cover it catch it.
