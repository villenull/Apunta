### 3a. Why the flows read facts over the API, and what must not be built

The observation hook is **absent from V3's bundle, and that is provable, not
hoped** (`04-observation-channel-absent.txt`): the gate is
`import.meta.env.VITE_APUNTA_TEST_IDENTITY === '1'` (`web/src/main.tsx:401`) —
a **Vite build-time** substitution — and P3.6's V0 runs the plain producer, whose
`npm run build` (`scripts/v2/package-linux-resources.sh:104`) sets no `VITE_*` at
all. With the variable absent the branch is dead and the minifier drops the hook
and its marker strings. So V3's bundle is **test-identity in Rust, unflagged in
the web app**. The card's own wording covers this ("through P3.4's observation
hook **where one exists** and otherwise through the app's own API over the sandbox
origin"), and P3.4 built its flagged bundle outside `web/dist` precisely so a
shippable bundle can never carry the gate.

Therefore, and this is the hard boundary:

- **No second hook, no second marker path, no gate change, no `src-tauri/**`
  edit, no capability, no `withGlobalTauri`, no `invoke_handler`, no injected
  script, no CDP/devtools attach, no eval-into-the-webview.** Those are the three
  forbidden remedies of Stop 5, verbatim. There is nothing to read in the DOM and
  nothing may be created to read it.
- **Actuation is `xdotool`; assertion is the app's own HTTP API on
  `127.0.0.1:7879`, plus the CSP header and the filesystem.** A screenshot is
  evidence and never the assertion; a screenshot of an unreached screen is a
  `FAIL`.

### 4a. The CSP assertion

Read from inside the harness over `http://127.0.0.1:7879/`, which is a
`text/html` response; `registerCsp` (`server/src/http/csp.ts:117`) decorates
**every** `text/html` reply and nothing else. Require, verbatim and separately:
`default-src 'self'`, `script-src 'self'`, `connect-src 'self'`,
`object-src 'none'`, `base-uri 'none'`, `frame-ancestors 'none'`, plus
`style-src 'self' 'nonce-<n>'` and `style-src-attr 'unsafe-inline'` — the nonce
is **fresh per response** (`freshNonce()`), so the additive pair is matched by
pattern, never against a literal. A missing header, a missing directive or a
weakened one is `FAIL`. Not read by a shell `curl` between launch and stop: the
harness holds the app up, so no moment exists in the row's own `&&` chain.
