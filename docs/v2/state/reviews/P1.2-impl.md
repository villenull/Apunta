1. **Non-blocking, residual coverage gap.** `rovingTarget`'s vertical arrows are

   vertical keys, so this is outside what the card asked for — worth two
   `fireEvent.keyDown` lines (or one `it.each`) in the ArrowLeft case if the

   code does handle them.
2. **Should be fixed before the coordinator merges, non-blocking for this
   card's criteria.** Evidence sanitization: `docs/v2/evidence/P1.2/v1-unit.md:19`
   and `:36` paste the vitest banner verbatim, which contains the absolute
   repository path and therefore the owner's username. Run-configuration §4
   requires the home folder to be written as `~` and usernames to be absent.
   Replacing those two lines with `~/Projects/Apunta` (or `<repo>`) fixes it; the
   rest of the evidence is properly sanitized — the v2 file strips host and pid
   fields and uses `<sandbox>/…` for the data dir, and neither file names a
   hostname, a key or a real person.
3. **Non-blocking, flake risk on local runs.** The added e2e case and P1.1's
   case now both write the single global `settings.theme` and run concurrently:
   `e2e/playwright.config.ts:45` sets `fullyParallel: true` and only pins
   `workers: 1` under CI. The new case leaves the row at `system`
   (`settings-appearance.spec.ts:111-117`), and the pre-existing case re-reads
   the server after its `page.reload()` (`:59-61`) and asserts Light — so if the
   new case's `Home` write lands between that click and that reload, the
   pre-existing test fails on an ordering, not on a behaviour. My run passed
   with the new case finishing first (263 ms against 544 ms), which is the
   benign order, and CI is unaffected because `workers: 1` serialises the file.
   A `test.describe.configure({ mode: 'serial' })` on this file, or restoring
   `theme: 'dark'` at the end of the new case, would remove the window.
4. **Non-blocking, observation on discriminating power.** The first new case
   ("is one tab stop…") starts from `STORED.theme = 'dark'`, which is also
   `DEFAULT_THEME` (`shared/src/settings.ts:88`), so on its own it would still
