## Verdict: **DEFECT** — sound about the mechanism, unsound about the controls

Genuinely established, re-verified rather than inherited: the exit-code discipline
(normal 0, blind 3, malformed 2, only the intended control flipping, `:218-227`);
`(?!)` over `(?:)` (`:189-193`); the literal-English legacy path byte-identical
(`:199-212`); the locale-scoped load error (`:194-198`); the English clinical file
unmoved under the Latin boundary (`:250-259`); the NFC precondition real at both

Findings **1** and **2** are **blocking for V2/V3**: the controls do not
discriminate faithfulness at all — they are inverted, B-1's mirror image rather
than its closure. 3–4 major, 5–8 minor, 9 a nit; each below carries its minimal
correction.

### 1 — the invented-negation control's source already carries a negation (blocking)

`:106` `SRC_NO_NEG = 'el paciente camina todos los dias y **no** hay antecedentes de
hipertension'`, used as `controlSource` at `:116`. Measured
(`node test-results/proof-review-s3/ce2.mjs`, exit 0):

```
controlSource contains "no": true
  FLAGGED  faithful: "No refiere antecedentes de hipertension."     <- the source's own meaning
  FLAGGED  faithful: "Jamás ha tenido antecedentes de hipertension."
  FLAGGED  proof's 'bad'  : 'No refiere antecedentes de hipertension. Niega dolor.'
  pass     proof's 'good' : 'Refiere antecedentes de hipertension.'  <- CONTRADICTS the source
```

`:108` asserts what the source says; `:109` asserts its opposite. The gold settles
that the source is wrong: real fixture
`invented-negation/01-todos-los-dias.txt` has no negation in its source ("su hermano
también es hipertenso", "diabetes desde hace seis años"), and its `mustNotContain`
is the gold list the proposal copied. **Minimal correction:** replace `SRC_NO_NEG`
with a negation-free source in the gold's shape, keep `:108` as the note that
inserts a negation and `:109` as a faithful restatement of it — one constant, one
note — and assert the source holds no inventory term.

### 3 — the bare `jam[aá]s` entry, and the guard that cannot see it (major)

`:129` keeps `'jam[aá]s'`, a bare negator with no phrase: measured above it flags
"Jamás ha tenido antecedentes de hipertension", the source's own negation restated.
That entry is safe in the gold only because *that* fixture's source holds no `jamás`
— a precondition stated nowhere and checked nowhere. The guard at `:180` is
`mustNotContain.filter(hole)`: it examines the 3 token-bearing entries and cannot
see the 4th, so the case named "no bare negator in `mustNotContain`" passes with one
present. The gold does carry `jam[aá]s` (all three fixtures), so the entry is not a
deviation; the missing precondition is. **Correction.** Extend the guard to every
entry (reject any entry whose entire surface is one inventory term) and gate on the
source precondition, or drop the entry and quote phrase-anchored alternatives.

### 4 — the correction narrows coverage (major)

Detection now works only in the `refiere` / `reporta` / `niega` slots. Measured
(`ce2.mjs`, exit 0): "Nunca ha tenido antecedentes de hipertension" and "No hay
antecedentes de hipertension" both **pass**. The gold covers other slots on purpose
— `"sin antecedentes de"`, `"no (?:camina|caminar|realiza actividad)"`,
`"no (?:hace|realiza) ejercicio"` — exactly what the token mechanism exists to swap.
**Correction.** Quote the gold's slot list with the token in each negator slot.

### 5 — the faithful lost-negation note bundles two sentences (minor)

`:111` bundles "No puede dormir bien. Sigue sin dormir bien."; `:170` passes.
Measured (`ce1.mjs`, exit 0): the first sentence **alone captures nothing** (`[]`),
the second alone captures the fact, and with the negation *dropped* from the first
the fact is **still captured** (1). The gold's `sueno-no-restaurado` holds eight
single-clause alternatives, so one sentence per case is available. (`no puede
dormir` was never a gold alternative, so its absence from the corrected list is
right.) **Correction.** One sentence, one gold alternative, per assertion.

### 6 — the `assertFixture` closure is asserted, not demonstrated (minor)

Report §3 claims the loader "hands a complete `Fixture` to an unchanged
`assertFixture`". `loadControl` (`:49-77`) hand-rolls it and never calls it: `f6` is
set nowhere, so `corpus.ts:123-135`'s gating branch is dead, and
`markerFreeSource` uses a four-alternative regex (`:66`) where `f6Core()`
(`patterns.ts:14`) has ~25 (`in keeping with`, `appears to be`, `secondary to`,
`differential`, …). A control whose source carries other marker vocabulary would
pass here and be refused in production. **Correction.** Drop the claim, or call
`assertFixture` with `f6: 'gating'` and `markerFreeSource` re-derived from
`f6Core()`.

### 7 — the existing-report guard is not atomic (minor)

`:268` `existsSync` then `:270` `writeFileSync` is check-then-act. Measured
(`ce1.mjs` E4, exit 0): `O_EXCL` is available (`128`) and unused; sequential calls
give `wrote`/`refuse` with bytes untouched, which is all a single-threaded toy can
show. The path it stands for is `cli.ts`'s bare `writeFileSync`, so the property
is the toy's. **Correction.** Open with flag `'wx'` and assert a second write
raises `EEXIST`.

### 8 — the attempt budget is modelled, not enforced (minor)

`:261` hardcodes `MAX_ATTEMPTS = 3`. The real counter is `state/cards/S3.2.json`
(`"attempt": 1`, measured) and the real rule is `build-dispatch.mjs:63-75`, which
**permits** attempt 4 given `--attempt-exception <AM-nnn>` naming an owner
amendment (the S2.5/AM-049 case). Report §3's "attempt 4 is refused as beyond the
existing budget" is therefore stricter than the shipped rule, and no real
enforcement is exercised. **Correction.** Read the card's counter, or state that
the proof bounds a model and enforces nothing.
