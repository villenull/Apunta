## 3. The minimum contracts (four, total)

Everything else in the 1,455 lines is commentary on these four.

### 3.1 Frame and target identity — one mechanism smaller than §E's

- **Publication identity = the rect-set signature `poll()` already computes** (`JSON.stringify(rects)`, `main.tsx` `poll`). Publish it as `frame=<that signature>` inside the **existing** batch loop. **No counter, no `frameSeq`, no new state.** One query parameter. It is strictly better than a counter: one publication ⇔ one signature (the hook publishes only on change), so "all batches carry the same `frame`" is *exactly* "all batches came from one publication", and a frame string cannot grow without bound.
- **Refresh on every sighting** (`entry.total = total; entry.frame = frame;`) — this is N2's remedy and is load-bearing: with create-once, a mixed read passes and a grown batch count makes completeness permanently unreachable.
- **Complete frame** = every index `0 … ceil(total/40) − 1` present, all declaring the same `total` **and** the same `frame`.
- **Claimed, and only this:** *a mixture of two publications is not selectable.* **Not claimed:** freshness. The hook publishes on change and never retracts, so a frame older than the page's current one is not decidable. No retraction protocol is sought — it is a new mechanism, and this card is out of attempts.
- **Selection predicate — one decidable rule:** among rectangles of a complete frame, match on the **pair** `(label, rectTag)`. Zero matches → the step's named cause. Two or more matches on the *same* pair → `FAIL` naming the count and the global indices. Two or more on *different* pairs → the unique pair is the target, and the others are recorded in evidence as a diagnostic. `rectTag` is thus load-bearing for selection, which is what removes N1 without adding a hover rule, and the same field is the first of the `clickEl` three-field comparison (M3: name `i{n}_l` as the third).

### 3.2 Calibration and click — one state machine, one deadline

**Delete** §C.2's 11-step prose. Replace with:

**States:** `BOOTSTRAP_1 → BOOTSTRAP_2 → CALIBRATED → SELECT → WARP → POINTER_VERIFIED → CLICK → CLOSE_LOOP → SETTLED`.

**Every state declares exactly four things:** precondition · one action · success predicate · its single terminal cause. No state has two exits for the same failure. No prose paragraph, no rationale, no counter-example.

| State | Action | Success | Terminal cause (one) |
|---|---|---|---|
| `BOOTSTRAP_1` | warp to `(windowX+cx₁, windowY+cy₁)` — the naive 1:1 guess, **stated as an assumption**, presses nothing | `ptrN` advanced, `ptrCX/CY/SX/SY` present | `NOT RUN` "no pointermove for bootstrap point 1"; **no click** |
| `BOOTSTRAP_2` | containment-check, then warp to `(X₁+Δcx, Y₁+Δcy)` — a displacement, affine-invariant | as above | `NOT RUN` "the bootstrap displacement left the window rectangle" (checked **before** the warp) or "no pointermove for bootstrap point 2" |
| `CALIBRATED` | solve `k_x, o_x, k_y, o_y` per axis | `0 < k ≤ 4` per axis | `NOT RUN` on the missing observation |
| `SELECT` | one complete frame, `(label, rectTag)` unique pair | rectangle found | `FAIL` "ambiguous: N rectangles share (label, rectTag)" |
| `WARP` | `mousemove --sync <X> <Y>` in **screen** space (no `--window`) | — | — |
| `POINTER_VERIFIED` | `getmouselocation --shell` read-back | `≤1 px` per axis **and** under our window (`WINDOW` id match, or `getwindowpid` = the same positive pid `windowInfo` read) | `FAIL` naming the delta, both window ids and pids |
| `CLICK` | `xdotool click 1` — **one click, never retried** | `clickN` advanced by exactly 1 and `\|clickC − T\| ≤ 2` | `FAIL` naming the observed `clickN` and the delta |
| `CLOSE_LOOP` | require a fact line with `clickN > preClick` **and** `href ≠ preClickHref`; then the most recent such line with `scriptText === 'true'` | both | `FAIL` naming which of the two did not change |

**The deadline — the only new thing, and it is not a new number.** `deadline = t₀ + 30_000`, where `t₀` is the instant of `BOOTSTRAP_1`, reusing the row's **existing, unwidened** 30 s click window. Every wait is `while (Date.now() < deadline)`; **there are no per-phase caps and no second budget**, so the arithmetic cannot fail and no timeout changes length. On expiry the state emits its own named terminal cause; if the deadline has already passed when `CLICK` would be dispatched, the row `FAIL`s naming the measured calibration cost. The 45 s first-fact window and §A.3's gate are untouched and still precede all of this.

*Consequence stated honestly, not hidden:* calibration now spends part of the click window. In the expected case it costs ~2 polls (< 1 s). In U-1's case (no `pointermove` from a synthetic warp) it consumes the window and ends `NOT RUN` with **no click issued** — which is the intended, named, safe outcome.

*Zero guesses:* `innerWidth/outerWidth` are published as diagnostics and a sanity bound only and are **never** read as the transform; no titlebar height is guessed; no `decorations(false)`; `src-tauri/**` stays untouched. The content origin is `(ox − windowX, oy − windowY)`, **derived**.

### 3.3 Exit status — one predicate, no shell

`spawnAsync` resolves `{ code, signal, stdout, stderr }`; one pure predicate `classifyCommandResult({code, signal, stdout, stderr})` returns `ok | FAIL(command, code, line)`. Any non-zero code or `XError` on `mousemove`, `getmouselocation` or `click` is an immediate `FAIL`. `clicked.ok` stops being discarded. All five existing call sites read only `.stdout` and are unaffected. Every invocation stays array-form `spawn` — no `sh -c`.

### 3.4 Cascade — one contract, three derivations

Single gate predicate: **a fact line whose `ipcProbe` is present and `!== 'pending'`**. One cause, a three-arm ternary: (0 marker lines) · (marker lines but no fact line) · (fact lines but `ipcProbe` never settled). Card text at `:584-593`, harness string, and the predicate are written **from this one line** in the same edit. Five `notRun` rows, unchanged order and semantics, one cascade, no second cascade, `resolved` still a `FAIL`.

> A rule enters this specification only if it is **(a)** traceable to a recorded observation in a prior attempt's evidence, **(b)** a failure produced by the executable model, or **(c)** a coordinator decision recorded under "not the owner's".
