## Numbered findings for the implementer

1. **`scripts/v2/tauri-e2e-smoke.test.mjs:948` drops every OCR word, so all
   eleven flows are `NOT RUN`.** The line
   `if (![left, top, width, height, confidence].every((value) => Number.isInteger(value))) continue;`
   requires an **integer** confidence, but tesseract **5.5.3 prints the TSV `conf`
   column with six decimals** (`92.934593`). Measured on this run's own window
   capture: 98 level-5 word rows, **0** survive the test, `screenWords` returns
   `null`, and the two call sites (`:1047`, `:1086`) render that as exactly the
   recorded causes. Reproduced with the shipped module's own exported
   `screenWords()` — no edit. With only that test relaxed to `Number.isFinite`,
   the same capture yields 95 words and `groundPhrase(..., "Add your note format")`
   returns `exactly once` with a box. **What makes it pass:** a coordinator-issued
   amendment to the harness so the confidence column is validated as a finite
   number rather than an integer — an edit this reviewer may not make (AM-214
   grants review and evidence only; Stop 5's forbidden remedies include any edit
   made to open a channel). **Whether it is the only defect is unknown; the row
   is spent and may not be repeated to find out.**
2. **`tauri build` deletes the sibling test AppImage instead of leaving it beside
   the production one** (observed, not a failure). After V1 the bundle directory
   held `Apunta_0.0.0_amd64.AppImage` and `Apunta.AppDir` only; V0's
   `Apunta (test)_0.0.0_amd64.AppImage` was gone. Every row counts its own
   identity pattern, so no assertion was affected, but a resumed session has **no
   test image** and must run V0 before V3. This is the behaviour AM-149 records as
   the open clean-or-add question of `tauri build`; recorded here so it is a fact
   rather than a surprise.
