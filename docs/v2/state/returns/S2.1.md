## Deviations

Four, none of which changes behaviour. Every one is inside a May-edit path and
every one is called out here rather than made quietly.

1. **`CreateNoteFormatRequestSchema.locale` is `.optional()`, not `.default('en')`.**
   Fixed decision 13 says "optional with default `'en'`", which in zod can mean
   `.default('en')` — and that reading puts `locale: 'en'` into the *parse
   output*, which fails the exhaustive `toEqual({ name, sections })` at
   `shared/src/schemas.test.ts:44`, a file this card does not own. The
   instruction review raised this as note 1. The behaviour the card requires ("a
   client that names no locale gets English") is delivered by the `createFormat`
   fallback Fixed decision 13 also mandates, so the two readings ship the same
   product. **The reading was chosen that keeps an unowned file green.**
2. **`SPANISH_AVAILABLE_SETTING` was added to `shared/src/settings.ts` and
   exported from `shared/src/index.ts`.** Fixed decision 4 requires the route to
   strip that key from a `PUT` and the response to publish it; the key's name
   belongs in `shared/` with every other settings key (`THEME_SETTING`,
   `LLM_PROFILE_SETTING`, …) so the client does not hardcode the string. The
   card's reason for licensing `settings*.ts` is "the `language` key name, the
   locale type re-export and the value guard", which does not name this constant.
   It is one exported string, in a licensed file, and nothing else moved.
3. **`CreateNoteInput.locale` and `CreateFormatInput.locale` are
   `locale?: string` with an `isLocale` guard, exactly as the card writes them.**
   A value that is not one of the two locales falls back to English rather than
   being cast, so the `NOT NULL` column can never hold a value the schemas would
   reject on the way out. Both call sites that pass a locale pass a `Locale`.
4. **The `PATCH /api/formats/:id` literal at `fakeApi.ts:729` was not edited.**
   Fixed decision 13 lists it as needing `locale`, and the review's line number
   was one short of the closing brace of the enclosing block. It needs nothing:
   the literal is `{ ...format }` plus optional overrides, and `format` is a
   `NoteFormat` from `makeFormat`, which now carries `locale`. The licensed edit
   at that line would have been a no-op, so it was not made. Nothing else in
   `fakeApi.ts` moved.
