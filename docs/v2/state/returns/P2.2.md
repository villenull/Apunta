## Deviations

1. **The zoom window is 1920×1080, not "at least 1800 px".** Exactly 1800 halves
   to exactly 900 CSS px, where `(max-width: 900px)` still matches and the home
   greeting has no box. The card's own stop condition for that trap says to fix
   the test's window size, so the test was written at 1920. This is the
   off-by-one the card's instruction review flagged; it changes no assertion and
   no production code.
2. **The unit test matches the mark's `viewBox` value by hand** rather than with
   `svg[viewBox="0 0 562 754"]`, because jsdom's `querySelector` never matches
   that attribute. Same value, same file's comment; the Playwright spec uses the
   selector verbatim because a real browser resolves it. This is a jsdom
   limitation, not a discrepancy in the shipped code.
3. **The card's four colour-test titles are built from the pinned constants**
   (`brand: light, default accent ${DEFAULT_ACCENT} — A mark ${…}`) rather than
   pasted as literals, so a title cannot drift from the value it announces. The
   rendered titles are character-for-character the card's.
4. **`afterAll` records a residual it cannot remove.** `PUT /api/settings` is a
   merge and no route unsets a key, so a key that was *absent* before the run
   stays stored at the last state's value. The spec asserts the restored value
   of every key that *was* present and prints the residual in its own output.
   Not a stop condition: `accent_color` ends at `#1f6f63`, byte-identical to
   `DEFAULT_ACCENT_COLOR`, and the only sibling spec that reads appearance state
   PUTs `theme` itself. Details in evidence `notes.md` §2.

None of these changes behaviour, and none is a May-edit violation.
