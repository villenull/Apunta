## Headline findings (unchanged in substance from the approved attempt 2)

- **Q1 tú/usted:** recommend **tú** for all UI addressed to the clinician.
  The Microsoft es-MX style guide recommends it explicitly, RAE notes that
  tuteo has spread to health personnel and patient relations, and the English
  voice is already informal. Counterpoint recorded: the Ubuntu Spanish style
  prescribes *usted*; Mexican plurals always take *ustedes* or third person,
  never *vosotros*.
- **Q2 formats:** dates in day–month–year order — numeric **DD/MM/AAAA**
  (DOF forms use DD-MM-AAAA) and machine **AAAA-MM-DD** per DGN-R-13-1973;
  prose dates with lowercase months. Times in the **24-hour** model for the app
  (`15:06`), `a. m.`/`p. m.` lowercase with periods if 12-hour is ever used,
  never mixing models; Mexican clinical precedent is a 24-hour field (UNAM
  ECLIME Psicología, "13:45 Hrs."). Decimal separator **point** in Mexico
  (RAE; NOM-008 allows point or comma, forbids grouping with them, requires a
  leading zero). **Sentence case** for UI labels, days and months lowercase.
  Interrogatives and exclamatives always carry **¿ / ¡**, with no period after
  the closing sign.
- **Q3 glossary:** 218 entries (715 `ui` strings) covering every visible noun
  and verb in `web/src/routes/*.tsx` and `web/src/components/*.tsx`, with the
  exact UI strings in each `ui` array so any string maps to an entry. Clinical
  renderings follow S1.1/S1.2 (nota de evolución, paciente, plan de
  tratamiento, motivo de consulta, cédula profesional); software terms follow
  Fundéu/Microsoft (copia de seguridad, lluvia de ideas); product names and
  identifiers stay as-is. The enumerator proves **0 unmapped** translatable
  strings.
