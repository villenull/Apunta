Headline findings:

- **Q1 tú/usted:** recommend **tú** for all UI addressed to the clinician; Microsoft's es-MX style guide recommends it explicitly, RAE notes tuteo has spread to health-personnel/patient relations, and the English voice is already informal. Counterpoint recorded (Ubuntu Spanish style prescribes usted; Mexican plurals always take ustedes/third person, never vosotros).
- **Q2 formats:** dates in day–month–year order, numeric **DD/MM/AAAA** (DOF forms use DD-MM-AAAA) and machine **AAAA-MM-DD** per DGN-R-13-1973; prose dates lowercase months. Times in the **24-hour** model for the app (`15:06`), `a. m.`/`p. m.` lowercase with periods if 12-hour is ever used, never mixing models; Mexican clinical precedent is a 24-hour field (UNAM ECLIME Psicología, "13:45 Hrs."). Decimal separator **point** in Mexico (RAE; NOM-008 allows point or comma, forbids grouping with them, requires a leading zero). **Sentence case** for UI labels; days/months lowercase. Interrogatives/exclamatives always carry **¿ / ¡**; no period after the closing sign.
