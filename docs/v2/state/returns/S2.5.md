## Deviations

Five, all forced by a shape change the card mandates, none of which changes
behaviour beyond what the card asked for. Each is a line or a declaration, not a
rule, a threshold or a guard.

1. **`server/src/index.ts:57-59`, not `:57-58`.** The card licenses two lines
   because `storageBootMessage`'s return shape changes. `storageBootFailure`
   returns a key, its parameters and the English `message` — the last so that
   `index.ts:59`'s `app.log.error(…, message)` still logs English. Without
   touching line 59 the file does not compile. Three lines, one of them a
   variable rename.
2. **`server/src/http/request-guard.test.ts` and
   `server/src/test/real-socket-guard.test.ts`**, one options object each. Not in
   May edit, and not editable without them: `BootErrorOptions` no longer has a
   `message`, so both suites are `tsc` errors otherwise. No assertion changed.
3. **`server/src/ai/types.ts` gained a `TranscribeOptions` interface**, and
   `WhisperOptions` now extends it. The card licenses `types.ts:274` (the
   `transcribe` signature) and `whisper.ts:46` (`WhisperOptions`); the interface
   is the declaration that signature needs. `TranscribeOptions` carries one
   field, the locale; the other twenty on `WhisperOptions` stay the provider's
   own configuration.
4. **`server/src/routes/chat.ts`'s `SERVER_SENTENCES` list**, extended with the
   three lock openings in **both** languages, read from the catalogues. The card
   licenses `chat.ts` for the fast-path reply and `finishWithReply`; this is the
   direct consequence of persisting a notice in the note's locale. Without it a
   Spanish note's thread keeps its own lock notice, `withoutServerSentences`
   fails to strip it, and the model reads it on the next turn — which is exactly
   the failure the locks exist to prevent. It is a display concern: it decides
   nothing about whether to block, what to count or what to log.
5. **The three `LlmProvider` streaming methods take the locale as an optional
   parameter** rather than a required one. Required would have meant editing
   about forty call sites in five test files for no behaviour change; optional
   with an English default leaves every existing caller exactly as it was, and
   all four production call sites (`routes/draft.ts`, `routes/chat.ts`,
   `routes/brainstorm.ts` and the three that share `streamDraft`) pass one
   explicitly. A required parameter would have been the stricter choice; the card
   says only that the signatures are licensed for this.

One design choice the card left open, recorded because a reviewer will want to
see it stated: **where a sentence is rendered.** A thrower that already holds a
locale — a job that captured one, or a refine that resolved the target note's —
renders on the spot, and the error is finished when it is thrown. A thrower that
does not leave it to `registerErrorHandler`, which now has a reader over the same
`db` and renders with the stored setting. Both produce the same sentence; the
difference is only which of C-LANG@1's three rules supplied the locale, and for a
request that is not a job and not a refine the stored setting is the right answer
anyway. `HttpError` keeps its `key` and `params`, so nothing is lost.
