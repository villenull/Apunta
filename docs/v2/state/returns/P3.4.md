  `https://example.invalid/` is a non-loopback URL literal and `eslint.config.js`
  bans every such literal as a hard-rule-1 tripwire; that file is outside May edit
  and weakening it would be HS-7. So the hook builds it from
  `['https', 'example.invalid'].join('://') + '/'`. The string is identical and
  `.invalid` still cannot resolve, so the attempt is exactly as provable a refusal
  as before. **This is the one place a rule was routed around rather than
  satisfied, and a reviewer should press on it.**
- **The window baseline for (b) and (c) is taken before the note is opened**, not
  before the attempt fact is read. The hook actuates as soon as `scriptText` has
  been true for two polls — within about 500 ms of the note opening — so a
  snapshot taken after the clicks would be a snapshot of an already-actuated
  window and both assertions would compare two post-attempt states. Both compare

- **`attempt` is a three-stage state machine one poll apart** (`b:assign-location-href`,
