   config greps are a weaker reading, the card forbids substituting them, and I did

3. **The inspector protocol is not readable from a plain TCP client on this build.**
   S3 requires the framing to be read off the bundled library rather than guessed,
   and it was: `WTF::SocketConnection::sendMessage(const CString&, GVariant*)`,
   `g_variant_new_bytestring` and the `method` / `params` / `targets` keys, all in
   `libwebkit2gtk-4.1.so.0`. On the wire, against the shipped AppImage: an unframed
   JSON message closes the connection in 0–1 ms; a GVariant-framed
   `((ay))`/`uint32`-length-prefixed message is buffered instead — and **no** framing
   out of sixteen, and no method name out of thirteen (`list`, `ListTargets`,
   `targets`, `getTargets`, `connect`, `evaluate`, `cancel` and variants, with and
   without `params`), produced a single reply byte in a 6 s wait. The card's stop
   condition applies and was followed rather than worked around.

4. **(d)'s handler half cannot be reached even with the channel.** Opening the note
   "by clicking the patient row and the note row located by their visible text"
   needs the page to be readable, so it shares the channel's fate. The three HTTP
   calls that precede it do run and did (formats 201, patient 201, note 201, with

## Decisions the card did not settle

  name the token in the test file, so the test builds it from parts
  (`['unsafe', 'inline'].join('-')`) and asserts that `csp.ts` names it on exactly
  one *executable* line — the `style-src-attr` one — and that this file names it on
  none. Prose is excluded, because prose describes a directive and cannot emit one.
  A second executable copy in `csp.ts` is precisely the substitution the card
  refuses, and it now fails the row.

  `e2e/fixtures/csp/injection-probe.md`, which the harness extracts by its fence
  rather than by line numbers, so the file's prose explaining the payloads can never
  end up inside a note.

  baseline taken **before** the launch, so the run's own single set is not mistaken
  for a second one, and additionally requires that the lock on disk names no live
  pid.
- **The harness is honest about the `NOT RUN`s and non-zero on them.** It prints one
  line per assertion, `NOT RUN` is never `PASS`, and the exit code is non-zero — so
  a row that cannot prove the contract cannot come back green.
