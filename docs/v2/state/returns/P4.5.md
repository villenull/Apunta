## What was built

`assertMayWriteEvidence()`: it returns `undefined` when `isEntryPoint()` is true
and otherwise throws an `Error` whose message says the probe was imported rather
than run and names `docs/v2/evidence/P4.1/redirects.md` as the file it refused
to write. It is `main()`'s **first statement** — before the artifact loop, so
before every `fetch`, and before the single `mkdir`/`writeFile`. The `writeFile`
order in `main()` is untouched (AM-064 refused to authorise changing it and this
card did not seek to). With the guard on the last line regressed to a bare
`await main();`, an import now runs `main()`, `main()` refuses on its first
statement, and the evidence file is untouched: harmless first, detected second.
The throw is deliberate; a silent `return` would restore the invisible failure.

**The evidence-bytes check** (Fixed decision 2). The suite reads
`docs/v2/evidence/P4.1/redirects.md` into a buffer at module top — above the
`globalThis.fetch` stub and above the dynamic import, so it is installed before
line `:101`'s import by construction — and asserts byte equality twice: in a
named case, and in the `after()` hook that already existed, which cannot be
reordered or skipped. Read-only; the path is resolved from the repository root
the same way the probe resolves `evidencePath`.

**`redactQuery`** (Fixed decision 3). Truncates at whichever of `?` or `#`
occurs **first in the string**, keeping that delimiter. `…?a=1#f=2` and
`…#f=2?a=1` both lose everything from the earlier of the two onward; a lone
query, a lone fragment and a string with neither behave exactly as before. The
rule is about position, not about which delimiter is more dangerous, and the
rejected alternative — "the first `#` whenever one exists" — is the *opposite* of
stricter: it would paste a whole signed query directly beneath a `query:` field
whose own text reads ``present — `<redacted>`, never pasted``. Case 10 is the
gate on it.

**User-info** (Fixed decision 4). Replaced inside the authority: everything
before its last `@` becomes `<redacted>`, the `@` is kept, so an authority
`user:pass@host` is written `<redacted>@host` and the host still reads. Only a
string that actually has an authority is touched — absolute (`scheme://…`) or
protocol-relative (`//…`) — so an `@` in a relative reference's first path
segment stays a path character. `user-info: present — refused` and the
`user_info_present` verdict are unchanged, so nothing is lost by removing the
credential.

**`escapeMarkdownInline`** (Fixed decision 5). One new export, applied at exactly
four display sites: the name in the `query_key_not_allowed` sentence, the name
list in `renderArtifact`, and the two `redactQuery` outputs. It replaces
U+0000–U+001F, U+007F, U+0060, U+005C and U+007C with the visible escape
`\uXXXX` in lowercase hex and touches nothing else — a name is escaped, never
dropped, never truncated. The two properties that keep this a rendering change
rather than a guard change are asserted, not merely intended: the membership test
still runs on the **decoded, unescaped** name, and `describeLocation().queryKeys`
is still returned unescaped and byte-identical to today (case 9). No verdict, no
sentinel, no refusal wording, no sort order, no host table and no `render` prose
moved. No export was removed and no export beyond the two the card names was
added.

## The residual (Fixed decision 6)

**The path is written as observed, and no path is redacted.** A token embedded in
a path is generically indistinguishable from a CDN's own content-addressed path,
and the one record that exists carries two 64-hex path components that are
artifact content rather than secrets. Redacting "token-shaped" segments would
mean inventing a new threshold inside this card, which HS-7 forbids and no owner
has authorised. So the residual is accepted, pinned by case 7 — a fabricated
64-hex path component asserted to **survive verbatim** with `redactQuery`
returning the `Location` byte-identical — and recorded in
`docs/v2/evidence/P4.5/residual-path-not-redacted.md` together with the
plan-editor action a real observation would require. This card observed nothing,
so nothing was reported under stop condition 3.

What is still guaranteed about a path is unchanged: it is written only after rule
