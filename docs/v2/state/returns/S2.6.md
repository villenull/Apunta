### AM-051's order, and how to check it

1. `cc71e31` changes only `t.test.ts` (plus its evidence). Check it out and run
   `npx vitest run shared/src/i18n/t.test.ts`. It fails with six lines, all
   `brainstorm.contextMostRecent`, in its `text` and `one` forms
   (`am051-step1-oracle-first.md`). The self-test case passes at that commit,
   because it injects its own defects into scratch copies and filters out
   lines the real catalogue already has.
2. `d509986` changes `es-MX.ts` and adds rendered-text pins, and the oracle goes green.

The oracle compares each form against the form `t()` would render in its
place in the other locale: same category, else `other`, else `text`. It
checks both directions, and it requires every form to print every name its
own `kind` declares. The union survives only as `unioned()`, which the
self-test uses to show that the union still matches English on each
injected case. The oracle does not use it.
