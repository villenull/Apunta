## 2. Which repair, and which of them is licensed today

**The repair is a catalogue value change, plus one new test case. It is not a
test-expectation change — and the one test-expectation change that *is* inside
May-edit is the one thing that must not be done.**

- **Catalogue value, `es-MX.ts` one key.** `language.en.english` must carry the
  name in English in every locale, exactly as its three siblings already do.
  That restores the `.english` key's established convention (`.english` is
  never translated; an endonym is a proper noun) and makes the Spanish screen
  mirror the English one. This is what both the review
  (`S2.6-AM059-implementation.md:244-250`) and the return
  (`state/returns/S2.6.md:163-165`) name.
- **Licence status — the file is writable, the key is not.**
  `shared/src/i18n/es-MX.ts` is in S2.6's May-edit three times over, but each
  grant is scoped **by key**: AM-051 for the per-form oracle and the two
  "de 1 notas" values; AM-059 for "the single `plan.attestationStatement` key";
  AM-054 licenses `en.ts`, not this file. `language.en.english` is none of them
  (`S2.6-AM059-implementation.md:274-290`). `en.ts` needs nothing and must not
  change.
- **The forbidden alternative, named so it is not walked into.**
  `e2e/tests/language-control.spec.ts` **is** inside May-edit (`e2e/tests/*.spec.ts`),
  so deleting the `checkScreen` call at `:382`, or moving it off the dialog,
  would make V1 green with no other change. It is a suppression: AM-059 says
  "Do not suppress `chat.change.summary` or add a no-English allow-list entry",
  AM-054 says "**Do not weaken this to make V1 pass**" and permits narrowing
  V1's screens only "if the walker is too noisy" — this is not noise, it is a
  mistranslation — and HS-7 forbids loosening a guard to make a result pass.
  **No spec change is proposed. No `ALLOWED` entry.**
- **The oracle gap that let it ship.** `web/src/components/LanguageDialog.test.tsx`
  has no Spanish-locale case: its only rendering assertions
  (`:59`, `:61`, `:72-76`) run under the English provider, so they pass while the
  Spanish screen reads differently. That file is outside May-edit.
