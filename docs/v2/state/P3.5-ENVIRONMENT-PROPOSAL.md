## 1. The blocker, in one paragraph

The AppImage bundles GStreamer's **core** libraries but no plugins and no
scanner, and `AppRun.wrapped` **unconditionally** sets
`GST_PLUGIN_SYSTEM_PATH_1_0=$APPDIR/usr/lib/gstreamer-1.0:<prior>`, replacing
GStreamer's compiled-in `/usr/lib/gstreamer-1.0`. The host's `libgstapp.so`
(which provides `appsink`) is therefore invisible inside the AppImage — hence
`GStreamer element appsink not found` while `gst-inspect-1.0 appsink` exits 0 on
the host. Separately `autoaudiosrc`/`alsasrc`/`pulsesrc` are genuinely **not
installed** (only `gst-plugin-pipewire` and the `-libs` packages). Two different
problems; `E6` alone fixes neither completely.

The supported fix for the first is one supported config key,
`bundle.linux.appimage.bundleMediaFramework` (`@tauri-apps/cli` 2.12.1 schema,
`default: false`): it makes the bundler copy the host's plugins **and** the
scanner into the AppDir and install an AppRun hook pointing at them. It cannot
add plugins the host lacks, so the install must come **first**.

- **U-1 `patchelf` is not installed** and the bundler's plugin script exits 2
  without it. Whether `linuxdeploy` supplies its own on the plugin's `PATH` was
  not established (no call-site disassembly). If it does not, step 1 fails

  (`/usr/lib/$(uname -m)-linux-gnu/gstreamer1.0/gstreamer-1.0`) does not exist on

  may dangle. Whether GStreamer then falls back to in-process scanning is
  upstream behaviour this repository cannot prove. Step 1 records it, step 2
  decides it.
- **Inference, marked:** the CLI's string table shows `--verbosity`, `gtk`,
  `gstreamer`, `failed to run linuxdeploy` adjacent, and
  `~/.cache/tauri/linuxdeploy-plugin-gstreamer.sh` exists — consistent with the
  flag selecting that plugin, not disassembled proof. That cached file's
  provenance is unknown; no download is needed or proposed.
- Whether the script filters "bad" plugins was not located. Not load-bearing.
- No external browsing was done and none is needed; if a later step needs
  upstream behaviour it is marked unknown here rather than fetched.
