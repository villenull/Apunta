added to `en.ts` and forgotten in `es-MX.ts` is caught. This card adds **118**

Two type errors did appear during the work and were fixed in the card's own
files, not worked around:

- `server/src/backup/index.ts` — the new stored-failure object was an
  `interface`, and only a `type` alias carries the implicit index signature
  `putSettings`' `Settings` (`z.record(..., z.json())`) needs. Fixed by making it
  a `type`, with the reason in a comment.
- `server/src/http/locale.ts` — `MessageParams` is declared in
  `shared/src/i18n/t.ts` but not re-exported from the package entry, and
  `shared/src/index.ts` is read-only for this card. Fixed by deriving the type
  from `t`'s own signature (`Parameters<typeof t>[1]`), which cannot drift from
  what `t()` reads.
