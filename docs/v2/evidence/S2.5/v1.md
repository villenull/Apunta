## The per-key placeholder case

`shared/src/i18n/t.test.ts` is in the filter and was not edited. It reads both
catalogues and compares the placeholder set of **every** key either holds, and
`es-MX`'s plural floor (`many`, `one`, `other`) for every counted key. This card
adds 118 keys and one counted plural entry (`errors.conflict.format_in_use`,
given all three es-MX categories); both cases pass without a change to that
file, which is the point of FD7: a missing `es-MX` entry is a `tsc` error, a
mismatched placeholder set is a `t.test.ts` failure, and neither is visible to
the other row.
