## Byte count is the bundle's own record, not a constant

`build/linux-resources/manifest.json` in the copy under test
(`<sandbox>/<runId>/bundle/linux-resources/manifest.json`) records for the same
path:

```json
{ "path": "web/dist/assets/index-D7iOgJVA.js", "bytes": 169523 }
```

The check keys the manifest on `web/dist` + the served path
(`web/dist/assets/index-D7iOgJVA.js`) and requires the served byte count to equal
that `bytes` value, so no threshold was invented. Measured as bytes, never as
`${#VAR}`: the shell and the asset differ enough under the run's UTF-8 locale
that a character count would fail a perfect bundle.
