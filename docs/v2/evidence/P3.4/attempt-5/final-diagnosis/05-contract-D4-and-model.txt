Approved contract §D.4 and the model's readback (source-proven defect)

docs/v2/state/P3.4-REPAIR-PROPOSAL-v5.md:154-159 (§D.4, owner-approved AM-188):
  "For every move ... wait (bounded by the one deadline) for a ptrN baseline,
   then dispatch and wait for a fact line whose ptrN is strictly greater; read
   the pointer back with `xdotool getmouselocation --shell` and require
   |X_read - X_asked| <= 1 and the same in y, plus `WINDOW` equal to the app
   window id **or** `PID` equal to the app's positive pid."

Harness implementation, faithful to the text:
  scripts/v2/tauri-security.test.mjs:1040-1047
    const sameWindow = String(read?.WINDOW ?? '') === String(window.id);

    const samePid = Number.isInteger(pid) && pid > 0 && pid === appPid;

Pure model mirrors the same logic:
  build/p3.4-spec-v5-repair2/model.mjs:299-311 (checkReadback, same WINDOW/PID).
