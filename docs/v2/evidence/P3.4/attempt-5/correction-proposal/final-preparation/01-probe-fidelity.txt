## 2. argument, order, control-flow and return-value equivalence

Every former `console.log(X)` became `emit(X)` carrying the **same single argument** — no
reordering, no argument added or dropped. `emit` is `process.stdout.write(format(...args)
+ '\n')`, which is console.log's own contract: arguments joined by `format`, one trailing
newline.

- **Return values.** `say` was `const say = (s) => console.log(s);` — an arrow *expression*
  whose value was console.log's `undefined`. It is now a block body,
  `const say = (s) => { emit(s); };`, so it still returns `undefined`; it does not return
  `emit`'s boolean, which `process.stdout.write` would otherwise hand back. Nothing reads
  `say`'s value, so getting this right cost nothing.
- **Formatting equivalence.** With no additional arguments, `format('%s and %d')`
  returns the unchanged string. The file contains one `%` in a comment, so the
  earlier zero-character claim was wrong. No printed string contains a format
  placeholder; unchanged print arguments and the replay establish fidelity.
- **Control flow** is untouched: no statement added, removed, reordered or re-scoped.
  Only the callee of each print changed.

## 4. normalisation, and the exact limit of what was normalised

Rule applied: `sed -E 's/[0-9]+ms/<ms>/g'` — every millisecond figure becomes a
placeholder. Deliberately blunt, so read what it covers: it also masks the **semantic
constants** printed alongside the timings (`BUDGET = 800`, the `BUDGET + 200 = 1000`
bound, `MOVE_MS = 150`). Those are probe **source constants**, not observations, and they
are proved unchanged separately: a diff of the two probe files shows only the 10 print
call sites, the added import, the destructure and the `emit` / `say` block. No constant,
budget, threshold or assertion string is edited. **No verdict and no status was
normalised** — every PASS line, every `ok=` / `killed=` / `survived=` / `problems (N)`
field and the final `ALL PASS` are compared literally.
