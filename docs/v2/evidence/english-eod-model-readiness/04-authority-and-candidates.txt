## Missing authority, exact

No `ACQUISITION.md` row names `ggml-tiny.en.bin`. A07 covers the six Spanish
C-STT candidates only; S4a.2 is parked and does not cover this file. HS-3 says
only items in `ACQUISITION.md` may be downloaded, so **no agent may download
it**. The one carve-out is hard rule 1's installer path, and hard rule 1(a)
makes starting it an owner action. This is the same shape as the existing
owner-only rows in `docs/v2/state/OWNER-ACTIONS.md:39,43` ("no ACQUISITION row
covers it (HS-3), so only you may install it").

**Therefore an owner action is required**: the owner explicitly starts the
existing installer's first run for exactly one English pinned `tiny.en`, to a
non-live path. No Spanish benchmark is unparked, no S4a.2 work is authorised,
and no A07 candidate is touched.
