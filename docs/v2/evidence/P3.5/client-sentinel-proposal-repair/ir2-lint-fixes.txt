# IR-2 - the author's evidence family now lints clean (13 errors -> 0)

Three bounded remedies, and nothing else.

1. `candidate-after.mjs` -> `candidate-after.mjs.txt`, BYTE-IDENTICAL content. It is a
   raw extraction witness, not an executable module (the proof reads it as text and
   evaluates it with `new Function`), so it carries a non-linted extension. This is the
   reviewer's preferred remedy: adding an export would have changed the witness.
2. `sentinel-proof.mjs` reports through `process.stdout.write(...)` instead of
   `console`, because the file sits under `docs/` and the `scripts/**` console
   exemption (eslint.config.js:116) does not cover it. Output-only: same text, same
   order, same stream, nothing added or dropped.
3. `sentinel-proof.mjs` - the unused destructuring
   `const { virtual, realMic, unrelated } = got.value;` is removed. The classifier
   call, the result object and the `got.value[key].length` / `got.value.all[0].clientId`
   reads that drive all 75 assertions are untouched. The binding is removed; the
   result access is not.
