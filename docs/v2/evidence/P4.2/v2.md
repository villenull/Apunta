## The build artefact really was absent

`rm -rf shared/dist` runs first, and it is the whole point of the row: the
sandbox reaches the shared function through
`../../shared/src/platform-paths.ts`, not through a build. Checked after the run
as well as before it:

```
$ ls shared/dist
ls: cannot access 'shared/dist': No such file or directory
```

`shared/dist` was still absent **after** the selftest and the `node --test` run
had both completed, so neither command created or needed it. A V2 run with
`dist` present would have proved nothing; this one cannot have used it.
(`.gitignore:2` keeps `dist/` out of the tree, and V1 and V3 recreate it.)

## Why the last test is the proof that the export was kept

`scripts/v2/sandbox.test.mjs` is **not** in May edit and was **not** modified.
Line 140 of that file does:

```js
const { platformDataDir } = await import('./sandbox.mjs');
```

so the sixth test can only pass because `platformDataDir` is still exported from
`sandbox.mjs`, re-exported straight from the shared module. Had the export been
dropped or renamed, that destructuring would be `undefined` and the case would
fail. The retained export is therefore proved by a file this card was not
allowed to touch — which is the honest way to prove it.
