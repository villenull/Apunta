## One thing this row made necessary, and why it is not a tsconfig edit

`shared` has **no Node types** in its build configuration: `shared/tsconfig.json`
has no `types` field, `shared/node_modules/@types` does not exist, and TypeScript
does not walk up to the root for the automatic `@types` inclusion. Only the
typecheck project sees any, and only because its test files pull `vitest`'s in.
A production module in `shared` therefore cannot name `process` — the read
Fixed decision 7 pins (`process.env['VITEST'] === 'true'` behind a
`typeof process !== 'undefined'` guard) does not compile as written.

`shared/tsconfig.json` is not this card's to edit, and no dependency may be
added, so `shared/src/i18n/t.ts` declares the shape it reads, module-scoped:

```ts
declare const process: { readonly env: Readonly<Record<string, string | undefined>> } | undefined;
```

The declaration is local to the module, so it shadows the global inside that one
file and **cannot leak**: `grep process shared/dist/i18n/t.d.ts` finds nothing,
and `@apunta/shared`'s emitted types require no `process` of any consumer. The
pinned expression is then used verbatim, and `typeof process !== 'undefined'`
narrows it.
