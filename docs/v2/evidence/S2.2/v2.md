## The bare default is still report-only

`scripts/check-ui-strings.mjs` has one constant, `REPORT_ONLY = true`, and the
bare invocation is what `npm run lint` ends with. It was **not** flipped to
failing here: S2.4 owns that switch, and doing it to quiet a red lint would be
loosening a guard (HS-7). V4 shows the bare step contributing 307 lines of
output and no exit code.
