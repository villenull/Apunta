## Nothing was loosened to get here (HS-7)

- No existing test was deleted, skipped, marked `.skip`, or weakened. The base's
  130 cases are all still present and still assert what they asserted.
- Six pre-existing `run.test.ts` cases changed their *fixture*, not their
  assertion: `speechModelPresent: true` used to write 25 arbitrary bytes and the
  base's `size > 0` rule called that "the model is installed". Under a pinned
  size that fixture is now `size_mismatch` by design, so those cases use a
  sparse file of the pinned length plus a valid receipt — which is what a real
  verified install looks like. Their expectations are untouched.
- `catalog.test.ts:26`'s pinned host list moved from three names to four because
  a redirect host was admitted, and `ALLOWED_DOWNLOAD_HOSTS` is now *derived* so
  that a fifth admission cannot skip the list.
- No threshold in `docs/v2/CONTRACTS.md` was touched; that file is byte-identical
  to the base.

## No test opened a socket, bound a port or needed a sandbox

appears in these files only as the Ollama base URL, which the guard never sees.
