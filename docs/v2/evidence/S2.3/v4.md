It is in `shared/src/i18n/t.test.ts`, a file this card's May edit licenses, and

condition. The cause was the two new literal category arrays in the case that

resolvedOptions().pluralCategories` already returns and which S2.2's original
case used implicitly. No assertion was weakened and no field made optional
(HS-7); the second `npm run typecheck` above is the run that counts.
