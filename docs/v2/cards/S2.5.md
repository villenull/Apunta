## Objective
Every server text a user sees (API errors, lock sentences appended to refine
replies, SSE status text, import reports, backup messages, the boot-error
page) is rendered from a code in the request's language.

## Read
`server/src/errors.ts`; `server/src/boot-error.ts`; `server/src/routes/chat.ts`
(appended lock sentences); `server/src/routes/draft.ts` (SSE status);
`server/src/import/*.ts` (report text); `server/src/backup/*.ts` (messages).

## May edit
Those files and their tests; the catalogues.

## Must not edit
Guard logic (only the sentence text moves to catalogues).

## Fixed decisions
- Language per request: the `language` setting, except that refine-lock
  sentences use the **target note's** locale (C-LANG rule 4).
- The boot-error page cannot read settings (storage failed): it shows both
  languages, English first.
- Persisted historical status text (import batch reports) is stored as
  code plus parameters from now on; old rows display as stored.
