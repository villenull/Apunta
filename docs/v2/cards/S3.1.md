## Objective
Fabricated Spanish dictations, split into tuning and held-out sets before any
prompt work, each with gold expectations written independently of the
production guards.

(independence, C-EVAL rule 9).

## Fixed decisions
- Written from scratch in natural spoken Mexican Spanish (fillers, restarts,
  out-of-order narration), not translated line by line from English.
- Organise fixtures by trap type: `<split>/<trap-type>/<name>.txt`, with
  **exactly 5 fixtures per trap type per corpus**. Within each trap type, sort
  by name and hold out indices `i` where `i % 5` is 1 or 3 (2 of 5 = exactly
  40%); the rest are tuning. The heldout share is
  `heldout/(tuning+heldout)` computed **separately for `eval-es` and
  `eval-owner-es`**, each at least 40%. Record the resulting lists.
- Gold expectations: one `expectations.json` per split root —
  `e2e/fixtures/eval-es/tuning/`, `e2e/fixtures/eval-es/heldout/`,
  `e2e/fixtures/eval-owner-es/tuning/`, `e2e/fixtures/eval-owner-es/heldout/`
  — with the same `_schema` keys as the English sidecars
  (`e2e/fixtures/eval/expectations.json`, `e2e/fixtures/eval-owner/expectations.json`),
  one entry per transcript, keyed by `<trap-type>/<name>.txt` relative to the
  split root. Prerequisite for S3.2: `loadCorpus` must recurse one level and
  key by that relative path (inside S3.2's `server/src/eval/**` May edit).
- Trap types (C-EVAL rule 4 and more): lost negation, invented negation,
  dose and number (decimals and units), experiencer (patient vs a family
  member), past vs current risk, uncertainty, spoken correction (S1.3
  markers), a section never covered, an English loanword, unclear speech,
  and clean controls. The English corpora's total fixture count is the
  minimum total.
- NAMES.md lists every fictional name used; nothing else appears.
