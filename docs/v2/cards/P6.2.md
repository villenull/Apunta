## Objective
A tag-triggered workflow builds and stages a **draft** release; the
production manifest never advertises unverified targets.

## Read
`.github/workflows/ci.yml`; `scripts/v2/check-release-config.mjs`.

## May edit
`.github/workflows/release.yml` (new); `scripts/v2/check-manifest.mjs` (new)
and test.

## Must not edit
`ci.yml`.

## Fixed decisions
- Trigger: tags `v*` only. Jobs: Linux AppImage; macOS arm64 and Windows
  builds as **artifacts only**, not in `latest.json`, until the owner marks
  them verified (a repository variable `APUNTA_VERIFIED_TARGETS`, default
  `linux-x86_64`).
- `tauri-apps/tauri-action` pinned by full commit SHA (A12); inputs checked
  against that exact version's documentation (v1.0.0 renamed inputs).
- Secrets referenced: `TAURI_SIGNING_PRIVATE_KEY`,
  `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` only. Release created as draft.
- `check-manifest.mjs`: validates `latest.json` schema, that every listed
  target is in `APUNTA_VERIFIED_TARGETS`, every artifact has a signature, and
  URLs point only at this repository's release assets.
