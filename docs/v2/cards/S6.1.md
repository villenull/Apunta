## Fixed decisions
- If S1.5 says DOES NOT FIT: implement nothing but a "not available" state,
  mark V1 to V3 `NOT RUN (no dictionary)`; Spanish stays held.
- Lazy load on Español only; a request id guards against an old language's
  load finishing after a switch; per-language personal word lists (existing
  English list migrates unchanged to `en`); load failure shows an error and
  leaves typing usable; works offline.
- Tokeniser keeps á é í ó ú ü ñ and treats ¿ ¡ as punctuation; Unicode
  normalisation to NFC without removing accents.
