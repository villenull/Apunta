## Fixed decisions
- Endpoint `https://github.com/villenull/Apunta/releases/latest/download/latest.json`,
  production public key only in the release config. Test endpoint and test
  key only under Cargo feature `test-updater`.
- Linux target: AppImage (E4); manifest key per the updater's
  `{os}-{arch}-{installer}` form (updater ≥ 2.10).
- Launch check after 30 s if the toggle is on; offline or failure is silent.
- The previous AppImage is kept beside the new one as `Apunta.previous.AppImage`
  for recovery mode.
- `check-release-config.mjs` fails if a release build's config or binary
  strings contain `127.0.0.1:78`, `127.0.0.1:789`, the test public key, or
  `dangerousInsecureTransportProtocol`.
