## Objective
Two properties of the one script that writes `docs/v2/evidence/P4.1/redirects.md`,
both owner-authorised on 2026-09-29 (`state/AMENDMENTS.md` AM-070) and both
carried out of P4.1 by its own reviews rather than fixed inside it.

1. **The probe checks that it was *run* before it writes anything.** Today the
   entry-point guard at `scripts/v2/probe-redirects.mjs:531` is the only thing
   between an import and seven `HEAD`s plus an overwrite of the record of record,
   and the suite can only notice a regression in it *after* `main()` has already
   written the file — DEF-2, `docs/v2/state/reviews/P4.1-attempt3-impl.md:340-361`.
   `main()` must re-assert the guard as its first statement, before the first
   request, and the regression must be observable without a human diffing the
   evidence file.
2. **Nothing that could be a credential, and nothing that could break the record
   as markdown, reaches the evidence file.** `redactQuery`
   (`probe-redirects.mjs:296-299`) truncates only from the first `?`, so a
   `Location` carrying user-info, or a fragment, or a fragment that looks like a
   query, is written verbatim; and a decoded query **name** carrying a character
   markdown acts on is written raw into the record.

The path is the one input class this card deliberately does **not** redact, and
Fixed decision 6 says why, with a test that pins the decision so a later change
has to be conscious.

## Fixed decisions
1. **The write precondition, and the one place it may sit.** One new exported
   function, `assertMayWriteEvidence()`: if `isEntryPoint()` (`:516-529`) is
   false it throws an `Error` whose message says the probe was imported rather
   than run and names `docs/v2/evidence/P4.1/redirects.md` as the file it refused
   to write; otherwise it returns `undefined`. It is called as the **first
   statement of `main()`** — before the loop at `:473`, therefore before every
   `fetch` and before `mkdir`/`writeFile` at `:486-487`. Not after the loop, not
   in the write helper, and not only in the tests.
   *Why in the script and not only in the suite:* with the last line regressed to
   a bare `await main();`, an import now runs `main()`, `main()` refuses on its
   first statement, and the evidence file is untouched — so the regression
   becomes harmless first and detected second, in that order. The throw is
   deliberate: a silent `return` would make the regression invisible, which is
   exactly the failure mode DEF-2 names.
2. **The evidence file is the oracle, and the check is installed before the
   import.** The suite reads `docs/v2/evidence/P4.1/redirects.md` into a buffer at
   module top, **before** the dynamic import at `:101`, and asserts byte equality
   twice: in a named case, and in the `after()` hook that already exists at
   `:102-104`. Read-only — neither file writes it, and the path comes from the
   repository root the same way `evidencePath` does (`:85-86`). This converts
   "discovered only by diffing against a previous run"
   (`P4.1-attempt3-impl.md:350-353`) into a failure the suite reports itself.
   Both places are required: a case can be reordered or skipped, a hook cannot.
3. **`redactQuery` truncates at the first `#` when there is one, otherwise at the
   first `?`, and keeps the delimiter it truncated at** — so a query renders
   `<prefix>?<redacted>` and a fragment `<prefix>#<redacted>`, and a `Location`
   carrying both loses everything from the `#`, because in URL syntax a `?` after
   `#` is part of the fragment. That is the shape today's code gets wrong:
   `…#token=1?x=2` currently redacts to `…#token=1?<redacted>`, which reads as
   redacted and is not (`P4.1.md:506-509`). A string with neither delimiter is
   returned unchanged, exactly as today. Nothing is lost by this: the record
   already carries `query:` (`:338`), `fragment:` (`:351`) and the
   `fragment_present` refusal (`:264`) as separate fields, so the raw line is the
   convenience copy, not the only copy.
4. **User-info is never written.** When the authority carries an `@`, everything
   before the last `@` that precedes the first `/`, `?` or `#` is replaced with
   `<redacted>` and the `@` is kept, so `https://user:pass@host/p` renders as
   `https://<redacted>@host/p` and the host still reads. This is a credential by
   definition and removing it costs nothing: `userInfo` already records whether
   one was present (`:288`, `:350`) and rule 1 already refuses it (`:263`).
5. **A name is escaped for markdown at the point of display, and nowhere else.**
   One new exported pure function, `escapeMarkdownInline(value)`: it replaces every
   C0 control character (U+0000-U+001F), U+007F, U+0060 (backtick), U+005C
   (backslash) and U+007C (vertical bar) with the visible escape `\uXXXX` in
   lowercase hex, and touches nothing else — a name is escaped, never dropped,
   never truncated, so a plan editor still reads every character of a name an
   allow-list might have to gain. It is applied at exactly four display sites:
   the name interpolated into the `query_key_not_allowed` sentence (`:271`), the
   name list in `renderArtifact` (`:347`), and the two `redactQuery` outputs
   (`:333`, `:367`).
   *The two properties that keep this a rendering change and not a guard change
   (HS-7), and both are asserted:* the membership test at `:270` runs on the
   **decoded, unescaped** name, and `describeLocation` returns `queryKeys`
   **unescaped** (`:287`). The backticks the code writes itself
   (`` `query_key_not_allowed` ``) live in the template, not in the value, so
   they survive; only a backtick that arrived inside a name is escaped.
6. **The path is written as observed. This is a decision with a reason, not an
   oversight, and it is the one thing a reviewer should attack hardest.** A token
   embedded in a path is generically indistinguishable from a CDN's own
   content-addressed path: the one record that exists carries two 64-hex path
   components that are the artifact's content and not secrets
   (`P4.1-attempt4-impl.md:250`), and the same review confirmed the committed
   file has no `#`, no authority `@`, and no `?` other than `?<redacted>`, with
   `user-info: absent` and `fragment: absent` on every artifact. Redacting
   "token-shaped" path segments would mean **inventing a new threshold inside this
   card**, which is precisely what HS-7 forbids and what no owner has authorised.
   So: no path redaction; a named test pins the deliberate preservation, so a
   blanket redaction later is a conscious change with its own evidence; and the
   residual is recorded in the return file and in `docs/v2/evidence/P4.5/`. What
   is still guaranteed about a path is unchanged — it is written only after rule 1
   has judged scheme, port, user-info, fragment and every query name
   (`:261-274`), and a `Location` that fails any of those is a recorded refusal,
   not a silent write.
7. **Nothing else about the record changes.** Same verdicts, same
   `UNDETERMINED` sentinel, same refusal sentences, same sort order and
   de-duplication in `queryKeyNames`, same host table (`:429-435`), same prose in
   `render`, same `exit` behaviour in `main`. No new export beyond the two named
   in decisions 1 and 5; no removed export.
8. **No egress, no new run, no new grant.** This card runs the probe **zero**
   times. P4.1's V2 stays `NOT RUN`, its grant stays spent, and AM-070 authorises
   no network of any kind — not a `HEAD`, not a re-resolution, not a DNS lookup.
   Every case is proven offline against the renderer with an injected `fetch` that
   throws (`:97-100`, already in place). That is why the fixtures are loopback
   literals and derived catalogue URLs and never a vendor: a vendor literal in a
   `.test.mjs` file fails V2 and fixing that would mean editing `eslint.config.js`,
   which is not editable.

## Stop conditions
1. **The precondition cannot be `main()`'s first statement** — some real caller
   reaches `main()` without being the entry point. Record the caller and the
   error and report `BLOCKED`. Do not move the check later, do not weaken it to a
   warning, and do not satisfy it by editing `scripts/package-mac.sh` or
   `installer/` (HS-9). A precondition after the loop is not this fix and is
   worse than nothing, because it would read as one.
2. **Escaping a name changes a decision.** If any implementation makes
   `describeLocation().queryKeys` escaped, or makes the membership test at `:270`
   compare an escaped name, or makes an admitted name stop being admitted — stop.
   Escaping belongs on the display side only (Fixed decision 5), and the fix is to
   move it, never to relax case 9 or to widen an `allowedQueryKeys` value.
3. **A `Location` whose *path* carries something that looks like a credential is
   observed in a real run.** This card does not run the probe, so this can only
   arrive as a report: record the exact `Location` with its query and fragment
   written `<redacted>`, report `BLOCKED`, and name the plan-editor action. Whether
   the path rule changes is the coordinator's and the owner's — a new redaction
   threshold is a contract-shaped decision (HS-7) and never one made inside this
   card.
4. **A fixture needs a non-loopback URL literal.** Derive from the catalogue or
   use `127.0.0.1`; a real vendor host fails V2 and is not a reason to edit
   `eslint.config.js` or to assemble a URL out of fragments to slip past the
   selector, which is loosening a guard (HS-7, Fixed decision 8).
5. **`docs/v2/evidence/P4.1/redirects.md` is already different from its committed
   content when this card starts.** Stop before running anything, do not run V3,
   and report: the record of record is not this card's to reconcile, and
   regenerating or hand-editing it is outside every clause above.
6. **Either item turns out to need a change outside May edit** — `installer/`,
   `eslint.config.js`, a contract, a threshold, a host rule, a query allowance, an
   `ALLOWED` entry, the `writeFile` order in `main()`, or another card's file.
   Report it as a finding for the coordinator and change nothing (HS-7, HS-9).
   AM-070 authorises exactly this card's two items and nothing else.
7. **V1 or V2 fails in a file outside May edit**, or the new suite cannot be made
   to fail on the unfixed probe: stop and report. A green suite that cannot fail
   is worse than no suite, and that is the defect DEF-2 is actually about.
