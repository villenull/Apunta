Playwright and the check scripts refuse unsafe targets under `APUNTA_V2=1`.

## Fixed decisions
- Until C-PATH@1 exists (P4.2), the wrapper computes the platform default
  with a local copy of the same table and a comment "replace with
  shared platformDataDir when P4.2 lands". P4.2 must replace it.
- `testRunId` appears in `/api/health` only when `APUNTA_TEST_RUN_ID` is set.
- The selftest never contacts port 7717; its "occupied port" and "foreign
  server" cases use dummy listeners it starts itself on 7880 to 7889.

## Known facts
Playwright sets `reuseExistingServer: !process.env['CI']` (line 64); the check
scripts default to `http://127.0.0.1:7717`.

## Steps

   them and record that they fail (wrapper absent).
2. Implement the wrapper. 3. Change Playwright and the two scripts.
4. Add the `/api/health` field and its unit test.
