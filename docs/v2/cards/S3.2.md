## Fixed decisions
- New flags: `--locale en|es-MX` (default `en`), `--mode provider|pipeline`
  (default `provider`, unchanged behaviour). Pipeline mode requires
  `APUNTA_CHECK_URL` (sandbox) and posts each fixture through the draft route,
  then reads the persisted note back through the API.
- Spanish lexicons for negation, number words, units and medications come
  from `docs/research/es-mx-clinical-glossary.json`, loaded by the scorer, not
  imported from production guard code.
- Controls per locale: positive controls (must be flagged), clean negatives
  (must pass), empty and degenerate outputs (must fail). `--fake` runs them.
- Output records model tag and digest, options, prompt-set hash, corpus hash,
  commit, hardware.
