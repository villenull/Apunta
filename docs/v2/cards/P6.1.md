Windows (NSIS), with per-target sidecar resources, ready for a first real run.

`scripts/package-mac.sh`; `docs/research/m8-shell-and-runtime-2026-08.md`.

(new), `scripts/package-mac.sh` (mark superseded in a header comment only).

## Fixed decisions
- macOS: signing identity `-` (ad-hoc); bundled `ollama`, `whisper-cli`, Node
  24.19.0 (arm64) with target-triple names per Tauri's sidecar convention.
- Windows: NSIS; WebView2 mode that downloads nothing when WebView2 is
  present (record the chosen mode); bundled Node 24.19.0 x64, `whisper-cli`,
  `ollama`, target-triple names.
- Every status for these targets is `CONFIGURED, NOT RUNTIME-VERIFIED`.
