## Follow-up filed by the coordinator (2026-09-28, from P3.1 attempt 1)

`scripts/package-mac.sh` bundles `server/dist/index.js` to ESM with
`--platform=node --format=esm --target=node24 --external:better-sqlite3` and **no
`--banner:js`**. P3.1's Linux packaging found that a bundle of exactly this shape
without the banner throws `Dynamic require of "node:stream" is not supported` at
load, because esbuild's CommonJS-in-ESM shim cannot satisfy a transitive
dependency's `require`. The Mac script almost certainly carries the same latent
boot failure and **has never been observed to boot**, so nothing has yet proved it
either way.

This is recorded here rather than fixed in P3.1 because `scripts/package-mac.sh`
is outside P3.1's edit scope and is this card's file. When P6.1 aligns Mac
packaging with the Linux work, it must decide: add the same banner, or record
why the Mac bundle does not need it. Do not treat the Mac bundle as working
because it has not been observed to fail.
