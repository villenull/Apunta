## Objective

it is the exact pinned artifact.

## Fixed decisions
C-ACQ@1 rules 1 to 7. Tests use a controlled local transport (an injected
`fetch` or a local HTTPS test server with a test certificate); **no test
contacts the internet**.

## Steps
1. Tests first: approved direct download; approved redirect; redirect to an
   unlisted host (refused before the second request is made); `http:`
   redirect; user-info URL; port 8443; redirect loop; 6 hops; checksum
   mismatch; interrupted `.part` resume; 11-byte file; zero-byte file;
   directory at the path; stale receipt after the file changed; valid
   receipt (no re-hash). Record failures.
2. Implement. 3. Run `probe-redirects.mjs` against the real pinned URLs with
   HEAD requests that **do not follow** redirects, recording each
   `Location` host, to confirm the CDN hosts.
