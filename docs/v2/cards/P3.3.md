## Objective
A Tauri 2 app starts the bundled server as its child, waits for its `ready`
line, shows the app, and shuts everything it started down cleanly.

## Read
`build/linux-resources/manifest.json` (P3.1); `server/src/index.ts`;
`docs/v2/assets/tauri-icons/`; DECISIONS E2, E3, E5, E7, E10.

## May edit
`src-tauri/**` (new); `package.json` (scripts `tauri:dev`, `tauri:build`,
`tauri:build:test`); `server/src/index.ts` (print the `ready` line; read
`shutdown` from stdin when `APUNTA_SHELL=1`); `server/src/shell-bridge.ts`
(new) and test; `.github/workflows/ci.yml` (Rust job: fmt, clippy, test);
`scripts/check-no-external-urls.mjs` (exclude `src-tauri/target`, allow the
Tauri schema URL by exact string).

## Must not edit
Update code (P5.4); web app.

## Fixed decisions
- Acquire A02 to A05 per ACQUISITION; record exact versions; commit
  `src-tauri/Cargo.lock` and the npm lockfile change.
- Identity `app.apunta.desktop`; test builds (`tauri:build:test`, Cargo
  feature `test-identity`) use `app.apunta.desktop.test` and read
  `APUNTA_DATA_DIR`/`APUNTA_PORT` from the environment, refusing to start if
  either is missing.
- Production: port 7717 (E5); if the server exits with a port error, show the
  error screen with code `port_in_use`.
- Single instance via `tauri-plugin-single-instance` (second launch focuses
  the window). Data ownership is C-OWN, not this plugin.
- Splash (brand A, no text needed) until `ready`; `fatal` or early exit →
  bilingual error screen with the code.
- Quit: send `shutdown`, wait 10 s, then SIGTERM the child's process group,
  then SIGKILL after 5 s. Never signal any process the shell did not spawn.

## Stop conditions
The installed Tauri version cannot load an `http://127.0.0.1` URL in the
main window without granting it capabilities: stop and report (E3 forbids
capabilities).
