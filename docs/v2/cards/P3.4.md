## Objective

and runs under a restrictive CSP.

## Read

absent); `server/src/app.ts` (static file serving); `server/src/boot-error.ts`.

## May edit

and `server/src/boot-error.ts` (register CSP); `scripts/v2/tauri-security.test.mjs` (new).

## Must not edit
Route handlers.

## Fixed decisions
C-BRIDGE@1 rules 4, 5, 6. Extra CSP sources only with a failing test as
evidence.
