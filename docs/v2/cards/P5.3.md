## Objective
The server can enter maintenance mode safely: every writer is registered,
new work is refused, active work drains, the editor flushes, and conflicts
refuse the transition. Window close uses the same rules.

## Read
`server/src/jobs/registry.ts` (S2.1); `web/src/components/NoteView.tsx`
(lines 260-335, flush); every route that writes or streams.

## May edit
`server/src/jobs/registry.ts`; `server/src/maintenance.ts` (new) and test;
routes (adopt the registry: all kinds listed in S2.1); `web/src/lib/maintenance.ts`
(new, client flush reporter) and test; `server/src/shell-bridge.ts`
(`quiesce` handling).

## Must not edit
Updater code (P5.4).

## Fixed decisions
C-UPD@1 "Quiescence" in full: 503 `maintenance`, 30 s drain, client report
`ok` or `conflict`, `quiesce_result{ok, blockers[]}`. Close: deferred during
a save; an active recording asks to confirm; flush failure keeps the window
open with the error.
