## Objective
WebKitGTK **captures** microphone audio inside the Linux app window and hands
it to the note's own transcript path, proven with intelligible synthetic English
speech; and silence or a tone never produces a note.

This card is **capture-only** (owner decision 2026-10-02, `AM-109`). It proves
two things and defers everything else to **S4a.2**:

- **Proved here:** the real `getUserMedia` → `AudioContext` → `AudioWorkletNode`
  → WAV path (`web/src/lib/recorder.ts`) receives frames from the host's capture
  device; the app's own record button really starts and stops it; the finished
  WAV is really POSTed by the app to `/api/transcribe`; and neither a tone nor
  digital silence creates a note.
- **How the last clause is proved here, stated honestly because the objective's
  wording cannot be taken literally in a card with no model.** With no model on
  disk, `WhisperProvider.transcribe` throws `whisper_model_missing`
  (`server/src/ai/whisper.ts:418-419`) before it reads the WAV
  (`detectTrailingSilenceDurationMs` is only reached at `:426`), so **nothing**
  produces a note in this card — speech, tone and silence alike — and "no note was
  produced" proves nothing about discrimination. **What this card proves instead
  is the half that needs no model:** a tone and digital silence both open the
  microphone, reach the app's own recorder and reach `/api/transcribe`, and they
  are **distinguishable from each other by the frames that arrive** — `levelPeak`
  is not `0` for the tone and stayed `0` for the silence (Fixed decisions, "The
  `--level` threshold is `0.01`"). **The end-to-end claim, that a non-speech input
  is refused with `transcription_empty` and no note is stored, is S4a.2's** and is
  deferred to it by name; `GET /api/notes` being empty is recorded as a
  *precondition* in every row, never as evidence.
- **Deferred to S4a.2 (the transcription half):** every claim about *words* —
  that the transcript contains the negated risk statement and the dose, the
  `transcription_empty` assertion, whisper accuracy, model selection (A07) and
  the `whisper_model` setting. **No model is acquired, downloaded, selected or
  run by this card** (HS-3; A07 belongs to S4a.2, which is `NOT STARTED`). A row
  that would need a model to pass is written here as deferred to S4a.2, never as
  a row that fails.

### Microphone containment (the host-global mutation)
The host's default capture device is a **real USB microphone**
(`alsa_input.usb-UGREEN_Camera_2K_…`). The run must never touch it. Owner
decision `AM-109`:

- **The virtual PipeWire source is the ONE permitted host-global mutation
  outside the run folder.** Nothing else in this card changes host state: the
  data folder, the port, the cache/config/XDG homes and the display all come
  from the sandbox environment and the harness, as in P3.3.
- **Mechanism, pinned for this host: PipeWire through `pactl` only.** This host
  runs `pipewire-pulse`; there is no `pulseaudio` daemon and no `pacmd`, and
  **neither may be used or installed**. The modules are provided by
  pipewire-pulse's own Pulse module layer — `module-null-sink` and
  `module-remap-source` are both implemented in
  `/usr/lib/pipewire-0.3/libpipewire-module-protocol-pulse.so` (verified by
  `strings`, read-only; no module was loaded while this card was written).
  `pactl` is 17.0 (`pactl --version`), so `pactl get-default-source` exists.
- **Exact commands, in this order, from the repo root:**

  ```sh
  PREV_DEFAULT="$(pactl get-default-source)"                     # 1. remember
  SINK_ID="$(pactl load-module module-null-sink \
      sink_name=apunta_p35 sink_properties=device.description=Apunta_P3.5)"
  SRC_ID="$(pactl load-module module-remap-source \
      source_name=apunta_p35_mic master=apunta_p35.monitor)"    # 2. create
  pactl set-default-source apunta_p35_mic                     # 3. default
  paplay --device=apunta_p35 --rate=16000 --channels=1 \
      "$(dirname "$APUNTA_DATA_DIR")/audio-en/dictation-30s.wav" &   # 4. feed
  #   ... the harness launches the AppImage and drives the real buttons ...
  pactl set-default-source "$PREV_DEFAULT"                      # 5. restore
  pactl unload-module "$SRC_ID"; pactl unload-module "$SINK_ID"  # 6. remove
  ```

  The names are `apunta_p35` / `apunta_p35_mic` in every row, so two runs never
  collide and V5 can assert on them exactly.
- **Step 3 happens before the AppImage is launched, and step 4 before the record
  click — and what that proves is now stated exactly, because the earlier text
  over-claimed it.** The Pulse default source is the only lever this card has:
  `web/src/lib/recorder.ts:258-266` passes `getUserMedia` a constraint object
  with `channelCount`, `echoCancellation`, `noiseSuppression` and
  `autoGainControl` and **no `deviceId`** — there is no `deviceId` anywhere in
  `recorder.ts` — so the app asks the platform for its default capture device
  and never names one. What the rows therefore **assert** is: the default source
  is `apunta_p35_mic` **before** the launch (`pactl get-default-source`), and
  `apunta_p35` is the only sink anything of this run plays into. What they also
  **observe and record**, from outside, while the recording is live, is
  `pactl list short source-outputs`: a capture stream must be present on
  `apunta_p35_mic`, and **no stream may be present on `alsa_input.usb-UGREEN`**
  (the owner's physical microphone) — that one is decidable from outside and is
  asserted, with the full output recorded verbatim in the row's evidence.
  **What the card cannot verify, and no row may claim: that the app opened the
  device the run made default.** Whether WebKitGTK's capture stack honours the
  Pulse default source at all is outside anything here, and nothing in this
  repository observes which node the stream attached to. The card says so rather
  than asserting a fact it does not have; the `source-outputs` read narrows the
  window, it does not close it.
- **The real-microphone stop condition is a stop, not a warning.** If, at any
  point before the record click, the current default source is a **physical**
  device — that is, `pactl get-default-source` prints anything other than
  `apunta_p35_mic` — then the virtual source could not be made the default
  first: the row **stops immediately and reports** `BLOCKED`, with V0's evidence
  and the live `pactl get-default-source` / `pactl list short sources` output,
  and does **not** launch the app and does **not** re-run. The same stop applies
  if `pactl list short source-outputs` shows any stream on
  `alsa_input.usb-UGREEN` while a recording is live: kill the AppImage by pid,
  let the teardown below restore and unload, then report `BLOCKED`. Recording the
  owner's room is the one outcome this card exists to make impossible, and an
  unobservable device is not a licence to proceed (HS-1, HS-8).
- **`trap`-based removal, on every exit path.** The harness installs
  `process.on('SIGINT'|'SIGTERM'|'SIGHUP')` and an exit handler that runs
  `pactl set-default-source "$PREV_DEFAULT"` and both `unload-module` calls, in
  that order, whether the row passed, failed, threw or was signalled. A row that
  cannot restore and remove is a `FAIL`, not a cleanup detail: the owner's
  microphone must be the default again whatever happened. **`PREV_DEFAULT`,
  `SINK_ID` and `SRC_ID` are written to `sideEffectsDone` in
  `docs/v2/state/cards/P3.5.json` as each row creates them**, so a resumed
  session can undo a half-finished run without re-deriving anything.
- **The playing stream is stopped by pid** (C-ISO@1 rule 7: never `pkill`), and
  `paplay` is never pointed at a sink other than `apunta_p35`, so the owner's
  audio output is untouched.
- **V5 is the only check that the source is gone** — and it is checked from the
  outside, not from the harness's own bookkeeping.
