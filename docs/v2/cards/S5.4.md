## Objective
Note drafting, refine, format detection, chat-composer dictation and the
retraction pass have full Spanish prompt sets, chosen from the captured job
context.

## Read
`server/src/ai/prompts.ts`; `server/src/routes/{draft,chat,formats-detect}.ts`;
`shared/src/job-context.ts`.

## May edit
`server/src/ai/prompts.ts` (or `server/src/ai/prompts/es-MX.ts`, new) and
tests; the three routes (capture job context at start; registry adoption)
and tests.

## Must not edit
English prompt text (snapshot tests stay byte-identical).

## Fixed decisions
- Prompts are written in Spanish, not English plus "answer in Spanish".
- Structured-output keys stay identical across languages; only text differs.
- Prompt budgets: Spanish prompts must fit the same context budget; a test
  measures the longest Spanish prompt against the budget code.
- Refine uses the **note's** locale (C-LANG rule 4).
