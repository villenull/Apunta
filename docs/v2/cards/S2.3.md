## Objective
Every user-visible string in the top bar, home, capture, note view and refine
chat comes from the catalogues, with es-MX text from the glossaries.

## Read
`docs/research/es-mx-ui-conventions.md`; `docs/research/es-mx-ui-glossary.json`;
`web/src/components/{TopBar,HomeLauncher,NoteView}.tsx` and the capture and
refine-chat components they use.

## May edit
Those components and their tests; `shared/src/i18n/en.ts`, `es-MX.ts`.

## Must not edit
Stored clinical text, enum values, identifiers, custom format instructions
(they are never translated).

## Fixed decisions
Visible text, aria labels, titles, placeholders, empty states, toasts and
errors are all catalogue keys. "Apunta" is never translated.

parameters: report it with its location.
