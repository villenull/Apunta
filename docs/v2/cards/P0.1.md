## Objective
Every development, CI and packaging path uses Node 24.19.0 (decision E1).

## Read
`.nvmrc`; `package.json` (`engines`); `.github/workflows/ci.yml`;
`scripts/package-mac.sh` lines with `NODE_VERSION` and `--target=node24`.

## May edit
`.nvmrc`; `package.json` (`engines` only); `.github/workflows/ci.yml`;
`docs/INSTALL.md` and `README.md` (Node version mentions only).

## Must not edit
`package-lock.json` except as `npm ci` leaves it (it must not change).

## Fixed decisions
- `.nvmrc`: `24.19.0`. `engines.node`: `>=24.19.0 <25`.
- CI uses `.nvmrc` (keep `node-version-file`).
- Install Node with ACQUISITION item A01 if the PC lacks it (into a
  user-local folder; do not replace the system Node the live instance uses).

## Known facts
`.nvmrc` is `22`; `engines` is `>=22`; `package-mac.sh` bundles Node 24.19.0;
the lockfile needs at least Node 22.22.2 or 24.15.0 for `jsdom`.

## Steps
1. Acquire Node 24.19.0 if missing (A01), verify its SHA-256, put it first
   on `PATH` for this repository's sessions only.
2. Edit the files above. 3. `npm ci`. 4. Run the verification rows.
