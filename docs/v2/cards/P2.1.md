## Objective
The top bar shows the 1a wordmark in `--brand-mark` colour; the favicon and
the in-app mark are the new A.

## Read
`docs/v2/assets/README.md`; `web/src/components/TopBar.tsx`;
`web/src/components/icons.tsx` (the scribble mark and its importers:
`grep -rn "<name of the mark export>" web/src`); `web/public/favicon.svg`;
the design-token stylesheet in `web/src/styles/`.

## May edit
`web/src/components/BrandWordmark.tsx` (new), `BrandMark.tsx` (new) and a
test for each; `web/src/components/TopBar.tsx` and its test;
`web/src/components/icons.tsx`; files importing the old mark (only the
import line); `web/public/favicon.svg`; the token stylesheet.

## Must not edit
`prototype/`; `--accent` and the accent picker; README screenshots.

## Fixed decisions
- `--brand-mark`: `#1f6f63` in light, `#ffffff` in dark (D10).
- Components inline the paths from `apunta-wordmark.currentcolor.svg` and
  `apunta-a.currentcolor.svg` with `fill="currentColor"`; colour comes from
  `color: var(--brand-mark)`.
- Wordmark height 22 px, accessible name "Apunta" (`role="img"`,
  `aria-label="Apunta"`); keep the old span's link and test id if any.
- `favicon.svg` is replaced byte for byte with the asset.
- No font file is added to the web bundle.

(for example a fixed-size setup screen): report the location; do not
redesign it.
