## Objective
A script produces a self-contained resource folder that runs the server with
the bundled Node 24.19.0, from any working directory, without the source
checkout or host Node.

## Read
`scripts/package-mac.sh` (lines 40-60, 225-240, 345-360: bundling, esbuild
target, SQLite binding copy); `docs/research/m8-shell-and-runtime-2026-08.md`;
`docs/research/m8-bundling-2026-08.md`; `scripts/build-whisper-candidate.sh`;
`server/src/config.ts` (`APUNTA_SQLITE_BINDING`, `APUNTA_WEB_DIST`,
`APUNTA_LICENSES_FILE`, migrations dir).

## May edit
`scripts/v2/package-linux-resources.sh` (new);
`scripts/v2/package-linux-resources.test.sh` (new); `.gitignore`.

## Must not edit
`scripts/package-mac.sh` (P6.1 aligns it later).

## Fixed decisions
- Output: `build/linux-resources/` with `node/` (A01, verified),
  `server/server.mjs` (esbuild, `--target=node24`), `server/migrations/`,
  `web/dist/`, `native/better_sqlite3.node` **compiled for the bundled Node's
  ABI** (run `npm rebuild better-sqlite3` using the bundled Node, never copy
  the host's), `bin/whisper-cli` (A06, built from the pinned revision) and
  its shared libraries, `THIRD-PARTY-LICENSES.md`, `manifest.json` listing
  every file with SHA-256.
- The script records the compiler and glibc versions in `manifest.json`.

## Steps
1. Write the test first: copy the output to a fresh temp folder, `cd /`, run
   the bundled Node with the bundled server under the sandbox wrapper
   (`--port` from the dispatch), with `PATH` stripped of the host Node, and
   check `/api/health`, a migration on a fresh database, creating a note, and
   `whisper-cli --help`. 2. Implement until it passes.
