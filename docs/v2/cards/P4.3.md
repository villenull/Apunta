## Objective
The installer plans exactly the effective writing model and the speech model
for the chosen language, using the benchmark's selection.

## Read
`docs/v2/state/STT-SELECTION.json`; `installer/src/catalog.ts`;
`installer/src/plan.ts`; `shared/src/transcribe.ts`.

## May edit
`installer/src/catalog.ts`, `plan.ts` and tests; `shared/src/transcribe.ts`
and test; `scripts/setup-macos.sh` and `scripts/preflight-macos.sh` (model
list text only); `docs/RECOVERY.md` (note the optional Spanish model).

## Must not edit
`config/recovery/current-linux.json` (it describes the live install).

## Fixed decisions
- If `result` is `SELECTED`: add the catalogue entry (publisher, MIT licence,
  size, SHA-256) and `speechModelFor('es-MX')`. If
  `NO QUALIFYING CANDIDATE`: `speechModelFor('es-MX')` returns `null`, and the
  plan refuses a Spanish setup with code `spanish_speech_unavailable`.
- `plan` input gains `language`; English plans are byte-identical to today's
  except the writing model now follows C-MODEL.

- Every catalogue entry takes `allowedQueryKeys` from its covering ACQUISITION
  manifest row. A07's enumerated names apply to its two existing speech entries
  and subsequent candidate entries covered by that row; other rows retain their
  explicit allowances. Catalogue tests must assert this mapping (AM-057).
